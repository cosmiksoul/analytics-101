Загрузка из файлов, баз и API

Чтобы собрать заказы магазина за квартал, понадобятся выгрузка CSV из CRM, база сайта и API мобильного приложения. Вы загрузите данные в DataFrame, проверите суммы и даты и сравните результат с данными из книги Excel.

01Как собрать заказы из трёх источников

Файлы читают с помощью read_csv и read_excel, запрос к базе выполняют через read_sql, а к API обращаются через библиотеку requests. У каждого источника свои особенности. Для файла нужно знать кодировку и формат дат и чисел, для базы — задать границы периода в запросе. У API нужно запросить все страницы и соблюсти лимит запросов. После загрузки проверим результат. Например, pandas может прочитать 4 января как 1 апреля без предупреждения.

Переходите между шагами кнопками или стрелками ← и → на клавиатуре.

Как описать формат CSV

В CSV значения записаны текстом, а границы полей обозначает разделитель. Чтобы правильно прочитать файл, нужно знать его кодировку, разделитель и форматы чисел и дат. В read_csv для этого есть несколько аргументов1217.

  • encoding задаёт кодировку. По умолчанию это UTF-8. Учебная CRM сохраняет файлы в cp1251, как в уроке 1.4.
  • sep задаёт разделитель полей. По умолчанию это запятая. В выгрузках с десятичной запятой поля часто разделяют точкой с запятой.
  • quotechar задаёт символ кавычек. Внутри кавычек разделитель считается частью текста. По умолчанию используются двойные кавычки.
  • decimal задаёт десятичный разделитель, по умолчанию точку. Аргумент thousands задаёт разделитель тысяч. По умолчанию pandas считает, что его нет.
  • dtype задаёт тип данных для столбца. Можно передать словарь с именами столбцов и их типами.
  • parse_dates указывает, какие столбцы содержат даты, а date_format задаёт формат их записи.
  • usecols позволяет выбрать только нужные столбцы.

Без dtype pandas определяет типы по значениям. Например, столбец с дробными числами получит тип float64, если pandas распознает десятичный разделитель. Для текста в pandas 3 используется тип str. В более ранних версиях по умолчанию использовался object3. Даты в нашем файле без parse_dates тоже останутся текстом.

Как прочитать листы книги Excel

В книге Excel ячейка может содержать число, дату или текст. Если дата записана в ячейке как дата, read_excel её распознает. Аргумент sheet_name позволяет выбрать лист по имени или номеру. При sheet_name=None функция прочитает все листы и вернёт словарь, где ключ — имя листа, а значение — DataFrame4. Для чтения файла .xlsx в примере используется openpyxl.

Как передать параметры в запрос к базе

Для подключения к базе используем SQLAlchemy. В строке подключения указывают тип базы, драйвер и адрес. Для PostgreSQL она может выглядеть так: postgresql+psycopg://user:***@host:5432/shop7. Функция create_engine создаёт объект для работы с соединениями. Его передают в read_sql вместе с SQL-запросом. Результат запроса возвращается в DataFrame5.

В параметризованном запросе вместо конкретных дат стоят метки :start и :end. Сами даты передают в словаре params. Так драйвер может обработать значения отдельно от команд SQL68.

Если подставить введённый пользователем текст в запрос через f-строку, он может изменить условие отбора. Это SQL-инъекция. Передавайте даты через параметры, чтобы сохранить структуру SQL-запроса8.

Проверьте типы столбцов после чтения. В учебной базе SQLite даты хранятся текстом. Чтобы получить столбец с датами, передайте в read_sql аргумент parse_dates. Числовой тип для суммы можно задать через dtype5.

Как загрузить все страницы API

Клиент отправляет HTTP-запрос по адресу вроде /v1/orders?page=1. Сервер возвращает код ответа и обычно передаёт данные в формате JSON. Код 200 означает, что запрос выполнен, 401 — что серверу нужны действительные учётные данные, 404 — что ресурс не найден. При превышении лимита запросов сервер может вернуть 429. Коды от 500 до 599 означают ошибки сервера. В requests.get можно задать адрес, параметры params, заголовки headers и timeout. Последний ограничивает время ожидания соединения и паузы между порциями данных9.

Заголовки содержат служебные сведения о запросе. В этом примере клиент берёт ключ из переменной окружения и передаёт его в заголовке Authorization.

Если сервер выдаёт данные страницами, такой способ загрузки называют пагинацией. Учебный API возвращает первые четыре заказа и номер следующей страницы в поле next_page. Клиент запрашивает этот номер и продолжает, пока не получит null (в Python — None). У другого API окончание списка может обозначать пустой массив или отсутствие ссылки на следующую страницу. Какой признак использовать, смотрите в документации.

Учебный сервер принимает запросы с интервалом не меньше двух секунд, то есть до 30 запросов в минуту. Если следующий запрос придёт раньше, сервер вернёт код 429 Too Many Requests10 и укажет в заголовке Retry-After, сколько секунд ждать11. При ответе 429 или ошибке сервера наш клиент делает паузу и повторяет запрос. Если сервер не указал время, клиент после каждой неудачной попытки удваивает паузу. Это экспоненциальная задержка.

В ответе API поле само может содержать несколько полей, например {"brand": {"name": "Бриз"}, "total": {"amount": 6348.6}}. Функция json_normalize создаёт из вложенных полей отдельные столбцы brand.name и total.amount12. Их можно переименовать в brand и amount, как в данных CRM.

Как сохранить типы данных в Parquet

В CSV даты и числа записываются текстом. При следующем чтении придётся снова указать их формат или довериться автоматическому определению типов. Parquet хранит значения по столбцам и записывает их имена и типы в схему13. В нашем примере to_parquet и read_parquet используют библиотеку pyarrow14, и после чтения столбец дат сохраняет свой тип.

03Как read_csv разбирает файл

Функция read_csv сначала декодирует байты в соответствии с encoding, затем выделяет записи и поля. Аргумент sep задаёт границу между полями. Если тот же символ находится внутри кавычек quotechar, он остаётся частью значения. В нашем файле первая строка содержит имена столбцов.

По умолчанию, если в середине файла встретится запись с лишним полем, read_csv остановится с ошибкой ParserError. Если же уже в первой записи на одно поле больше, чем в заголовке, pandas может принять первое поле за неявный индекс. Тогда имена столбцов будут относиться к остальным полям.

Затем pandas определяет типы. При чтении чисел он учитывает decimal и thousands, для столбцов из dtype использует указанные типы, а столбцы из parse_dates пробует преобразовать в даты. Без date_format pandas определяет формат по первому непустому значению1. В нашем файле это 04.01.2026. При стандартных настройках pandas читает её как 1 апреля, хотя заказ был 4 января.

Тренажёр воспроизводит работу read_csv на JavaScript. Для исходного файла проверены все 384 сочетания настроек. Таблицы, типы и сообщения об ошибках совпали с результатами pandas 3.0.5. Различаться может порядок имён в списке отсутствующих столбцов. Можно вставить свой текст, но для него результат лучше сверить в pandas.

После загрузки сверьте число строк и столбцов (df.shape) и типы данных (df.dtypes). Затем посмотрите на самую раннюю и самую позднюю даты в df["date"] с помощью min() и max(). Обе должны попасть в нужный период.

04Типы, большие файлы и ключи доступа

Укажите ожидаемый тип суммы. Если в выгрузке за неделю суммы записаны целыми числами, pandas определит тип amount как int64. В следующей выгрузке может появиться 1569,80. Без decimal="," столбец станет текстовым. Если вы задали dtype={"amount": "float64"}, чтение остановится сразу с сообщением ValueError: could not convert string to float: '1569,80'.

Читайте большие файлы по частям. С аргументом chunksize функция read_csv возвращает итератор. На каждом шаге он выдаёт очередной DataFrame с заданным количеством строк или меньше2. Чтобы посчитать общую сумму, прибавляйте сумму каждой части к промежуточному итогу. Так можно обработать файл, который целиком не помещается в память. В примере chunksize=3 делит восемь заказов на три части по 3, 3 и 2 строки.

Храните ключи доступа отдельно от скрипта. Если записать пароль от базы или ключ API в коде, его легко случайно отправить вместе со скриптом. В примере клиент читает ключ из переменной окружения через os.environ["SHOP_API_TOKEN"]15. Если вы храните настройки в файле .env, добавьте его в .gitignore до первого коммита. Ключ передавайте в заголовке запроса. Адрес с параметрами может попасть в журнал сервера.

Задайте формат даты. Без parse_dates столбец date в нашей выгрузке имеет тип str. При сортировке текст «02.03.2026» окажется раньше «04.01.2026», хотя март идёт после января. Если указать parse_dates без формата, pandas может принять первое число за месяц. А если дальше встретится 14.01.2026, она не подойдёт под такой формат и весь столбец останется строковым. Здесь нужны оба аргумента: parse_dates и date_format.

06Как загрузить заказы и сохранить результат

Для каждого источника есть отдельный модуль с функцией чтения. Первый модуль загружает файл CRM с явными типами. В конце примера видно, как изменятся суммы и даты, если указать неверные настройки.

Второй модуль читает заказы из базы. В материалах есть файл SQLite с таблицей orders, поэтому устанавливать сервер базы данных не нужно. Обратите внимание, как функция read_site передаёт даты в запрос.

Третий модуль загружает заказы из приложения. Учебный сервер на http.server16 запускается на вашем компьютере. В нём десять заказов, которые он выдаёт страницами до четырёх записей. Для доступа нужен учебный ключ из переменной окружения. В конце примера клиент дважды подряд запрашивает первую страницу, чтобы показать обработку ответа 429.

Скрипт добавляет к семи общим столбцам восьмой, source, чтобы сохранить источник каждого заказа. Затем pd.concat объединяет три таблицы. Результат записывается в Parquet и CSV, чтобы можно было сравнить типы после чтения.
