Условия, циклы, функции и comprehensions

После этой страницы вы напишете фильтр, преобразование и итог для выгрузки любой длины без копипаста и прочитаете чужой код, где всё это свёрнуто в одну строку comprehension.

01Идея: решить для одной строки и повторить для всех

Чтобы не копировать одну и ту же проверку на каждую строку, в Python есть четыре инструмента. Условие решает, что делать с одним значением, цикл повторяет действие для каждого элемента, функция даёт куску кода имя, а comprehension записывает цикл одним выражением.

Листайте шаги кнопками или стрелками ← → на клавиатуре. Ниже — подробно: в этом разделе условия и циклы, в следующих — функции и comprehension.

if, elif, else: ветки и отступы

Условие if вычисляет выражение и выполняет вложенный блок, только если получилось True. Блок задаётся отступом: строки, сдвинутые на четыре пробела под if, относятся к нему, а первая строка без сдвига — уже нет. Фигурных скобок и слова «конец» в Python нет, поэтому отступ — часть синтаксиса, а не оформление.

elif («иначе если») добавляет следующую проверку, else ловит всё остальное. Python идёт по веткам сверху вниз, выполняет первую, чьё условие истинно, а следующие уже не проверяет1. Поэтому порядок важен: если первой поставить проверку a >= 1000, до ветки a >= 2000 крупный заказ не дойдёт.

Истинность: что if считает ложью

В if можно поставить не только сравнение, но и любое значение. Тогда Python проверяет его истинность: ноль, пустая строка, пустая коллекция и None считаются ложью, всё остальное — истиной4. Это удобно: if brands: читается как «если список не пуст». Но в данных это ловушка: сумма 0 ₽ и пропущенная сумма для if выглядят одинаково.

for: одно действие для каждого элемента

Цикл for перебирает коллекцию: кладёт очередной элемент в переменную цикла и выполняет тело — блок с отступом под for. Один такой проход называется итерацией. for row in rows: читается как «для каждой строки выгрузки»: строк восемь — восемь итераций, сто тысяч — сто тысяч, а код тот же.

Три помощника закрывают почти все случаи2. range(n) выдаёт числа от 0 до n − 1, когда важно число повторов, а не сами элементы. enumerate(rows, start=1) отдаёт пары «номер, элемент»: удобно нумеровать строки отчёта. zip(brands, amounts) идёт по двум спискам в ногу, отдаёт пары «бренд, сумма» и останавливается на самом коротком списке.

while: пока условие истинно

Цикл while повторяет тело, пока условие истинно. Он нужен, когда число повторов заранее неизвестно: например, читать страницы API, пока не придёт пустая. Выход — ваша забота: если условие никогда не станет ложным, цикл не закончится. break прерывает любой цикл досрочно, continue пропускает остаток итерации и переходит к следующей1.

В примере ниже — все конструкции раздела на суммах со страницы 1.1. У while четыре заказа дают 4 990 ₽, до плана в 5 000 ₽ не хватает десяти рублей, и цикл берёт пятый.

02Задача: одно действие для каждой строки

На странице 1.1 выручка считалась по пяти суммам. Теперь учебная выгрузка заказов посложнее: у каждой строки бренд, сумма и статус, а бренд записан как попало — «BRISA», «brisa», «Brisa » с пробелом в конце. Нужно оставить оплаченные заказы, привести бренды к одному написанию и посчитать выручку по каждому.

В Excel это фильтр, формула, протянутая вниз, и сводная таблица. В Python первое желание — написать проверку для первой строки и скопировать её на остальные. Такой код работает, пока строк восемь. Завтра их девять, через месяц сто тысяч, и любую правку придётся вносить во все копии.

Задача страницы — записать проверку, преобразование и агрегат один раз, чтобы они работали на выгрузке любой длины, и научиться читать чужой код, где всё это уместилось в одну строку.

03Функции: имя для повторяемого куска

Функция — именованный кусок кода, который выполняется при вызове. Её объявляют словом def, а вызывают по имени со скобками: clean_brand(" lumo"). Значения в скобках при вызове — это аргументы, а имена в объявлении, которые их получают, — параметры. return завершает функцию и отдаёт результат тому, кто её вызвал; функция без return возвращает None.

Параметру можно дать значение по умолчанию: def clean_brand(name, default="Без бренда"). Такой аргумент можно не передавать или передать по имени: clean_brand(raw, default="—"). Аргументы по имени читаются лучше, когда их больше двух: не нужно помнить порядок.

Строго говоря, функция возвращает одно значение, но им может быть кортеж: return len(paid), sum(paid). При вызове кортеж раскладывают по переменным — это распаковка: n, total = paid_stats(rows).

Область видимости: что видит функция

Параметры и переменные, созданные внутри функции, существуют только во время вызова и видны только ей. Это её локальная область видимости. Имена верхнего уровня ноутбука или скрипта глобальные: функция может их прочитать, но присваивание внутри функции создаёт новую локальную переменную и глобальную не трогает7.

Так сделано, чтобы функцию можно было понять отдельно от остальной программы: всё нужное приходит через параметры, результат уходит через return. Функция, которая втихую читает глобальные переменные, ведёт себя как ячейка со страницы 1.1: работает, пока в памяти лежит нужное.

04Comprehensions: цикл, свёрнутый в выражение

Comprehension строит новый список из коллекции одним выражением в квадратных скобках. Устоявшегося русского термина нет, иногда говорят «списковое включение». [row["amount"] for row in rows if row["status"] == "paid"] делает то же, что цикл из четырёх строк в анимации: перебирает rows, оставляет оплаченные и кладёт в результат сумму2.

Читать его удобнее в порядке выполнения, а не слева направо: сначала for — откуда брать, потом if — какие оставить, и только потом выражение в начале — что положить. Если скобки фигурные, а в начале стоит пара «ключ: значение», получается словарь, dict comprehension. {brand: round(s / total * 100) for brand, s in totals.items()} превращает выручку брендов в их доли.

Когда comprehension хуже цикла

Цикл лучше comprehension в четырёх случаях.

  • Два for подряд. В [x for day in days for x in day if x] внешний цикл пишется первым, и это приходится вспоминать.
  • Два разных if. В [a if a > 0 else 0 for a in amounts if a is not None] слева условное выражение, справа фильтр, и легко перепутать, что из них что.
  • Нужен побочный эффект: печать, запись в файл, дописывание в другой список. Строить список ради print — значит выбросить результат.
  • Нужна отладка. У копящегося списка нет имени, промежуточного состояния не видно — это заметно в трассировке ниже.

Правило простое: если comprehension не пересказывается одной фразой, разверните его в цикл.

05Трассировка: что происходит при вызове функции

Трассировка — запись выполнения программы по шагам: какая строка выполняется, какие переменные существуют и кто кого вызвал. Так работают визуализатор Python Tutor8 и интерактив ниже. Трассу для него записал настоящий Python 3.13 через функцию sys.settrace, которая сообщает о каждой строке, вызове и возврате9.

Главное, что видно в трассировке, — стек вызовов. Когда одна функция вызывает другую, Python кладёт поверх текущего кадра новый. В кадре лежат параметры и локальные переменные этого вызова и строка, на которой он сейчас стоит. return снимает кадр, и его переменные исчезают6. Сначала предскажите, что окажется в кадре clean_brand.

Переключите версию на comprehension. Строк кода меньше, а шагов не меньше: работа та же, меняется только запись. Своего кадра у comprehension нет: с Python 3.12 интерпретатор встраивает его в код функции, но переменная row наружу по-прежнему не выходит10. А копящийся список вы так и не увидите: имени у него нет, пока comprehension не закончится.

Рекурсия как идея

Функция может вызвать сама себя — это рекурсия. Стек при этом растёт так же, как в трассировке: каждый вызов — новый кадр со своими переменными. Рекурсия удобна для данных, вложенных сами в себя: дерево каталога, папки в папках, JSON с вложенными объектами.

Чтобы вызовы закончились, нужен базовый случай — вход, на котором функция отвечает сразу и себя не вызывает6. В примере ниже это раздел без подразделов, где лежит просто число товаров. Глубина стека ограничена: по умолчанию предел — 1 000 кадров, глубже Python остановится с ошибкой RecursionError9.

06Нюансы: значение по умолчанию, переменная цикла, ранний return

Изменяемое значение по умолчанию. Значение по умолчанию вычисляется один раз, когда выполняется def, а не при каждом вызове1. Для числа или строки это незаметно, а список создаётся один на все вызовы и хранится в самой функции, поэтому def f(x, acc=[]) дописывает каждый новый x в тот же список. Исправление — None по умолчанию и новый список внутри функции.

Переменная цикла живёт после цикла. for не создаёт своей области видимости: после цикла row хранит последнюю строку выгрузки5. Опечатка ниже цикла, row вместо r, не даст ошибки и молча возьмёт эту строку. Если выгрузка пустая, цикл не сделает ни одной итерации, и переменная не появится вовсе. У comprehension, наоборот, своя область: его переменная наружу не выходит.

Ранний return вместо вложенных if. Когда проверок несколько, вложенные if уводят логику вправо, и у последнего else уже не вспомнить, к какой проверке он относится. Ранний return переворачивает порядок: сначала отсеять особые случаи и сразу вернуть ответ, а основной случай оставить в конце без отступа. Результат тот же, а функция читается сверху вниз.

07Ограничения: в pandas цикл по строкам почти всегда ошибка

Всё на этой странице — чистый Python. В таблице pandas цикл по строкам становится ошибкой: pandas хранит столбец как массив значений одного типа и применяет операцию ко всему столбцу за один вызов. Это векторизация, а цикл for по строкам или df.iterrows() её отключает: каждая строка снова превращается в объекты Python. Документация pandas прямо предупреждает, что перебор строк обычно медленный и чаще всего не нужен11.

08Код: очистка бренда, список файлов, генератор

Функция очистки бренда собирает приёмы страницы: значение по умолчанию, ранний return, цикл с условием, агрегат и dict comprehension для долей. Данные — учебная выгрузка из анимации.

Comprehension для списка файлов. В учебной папке exports лежат ежедневные выгрузки вперемешку с возвратами, файлами Excel и README. Одно выражение оставляет нужные, второе строит словарь «дата → файл» срезом имени (срезы — на странице 1.2).

Генератор — функция, в которой вместо return стоит yield. Вызов такой функции ничего не выполняет, а возвращает объект, который отдаёт значения по одному, когда их просят. Это частный случай итератора — объекта, у которого можно попросить следующий элемент через next()3. for перебирает любой итератор, поэтому генератор встаёт туда, где раньше был список. Comprehension в круглых скобках вместо квадратных — генераторное выражение: тот же цикл, но без списка в памяти.

Аналитику это нужно для файлов, которые не помещаются в память. Учебный файл ниже — миллион строк. Список из всех строк занял около 360 МБ, генератор при том же результате — 0,03 МБ.
