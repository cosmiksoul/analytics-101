Условия, циклы и функции

У магазина восемь заказов. Чтобы посчитать выручку по брендам, нужно выбрать оплаченные заказы, убрать лишние пробелы в названиях брендов и сложить суммы. Вы напишете цикл для этой задачи и функцию для очистки названий. Затем увидите, как построить список или словарь одним выражением с помощью включения (comprehension).

01Как обработать все строки выгрузки

Начнём с одного заказа. Условие проверит его статус. Цикл повторит проверку для каждого заказа в выгрузке. Если одну и ту же операцию, например очистку названия бренда, нужно выполнять в нескольких местах программы, её удобно оформить как функцию.

Переключайте шаги кнопками под анимацией или стрелками ← и → на клавиатуре.

Как Python выбирает ветвь if, elif или else

Python проверяет условие после if. Если оно истинно, выполняется вложенный блок. Его строки выделяют одинаковым отступом, обычно в четыре пробела. Когда отступ возвращается к уровню if, блок заканчивается.

После elif («иначе если») указывают ещё одно условие. Ветвь else выполняется, если ни одно условие не подошло. Python проверяет ветви сверху вниз и останавливается на первой подходящей1. Если сначала проверить a >= 1000, заказ на 2 300 ₽ уже попадёт в эту ветвь. До проверки a >= 2000 программа не дойдёт.

Что считается истинным в условии

В условии if можно использовать значение напрямую. Python проверяет его истинность4. Например, if brands: выполняет блок, когда список брендов содержит хотя бы один элемент. С суммами нужно быть внимательнее. Для нуля и для пропуска, записанного как None, проверка даст один и тот же результат.

Как for перебирает элементы

Цикл for по очереди присваивает переменной цикла значения из последовательности и выполняет для каждого тело цикла. Один такой шаг называют итерацией. В цикле for row in rows: переменная row на каждой итерации указывает на очередную строку выгрузки.

range(n) удобно использовать, когда действие нужно повторить n раз. При положительном n перебор начинается с нуля и заканчивается на n - 1. enumerate(rows, start=1) даёт строку вместе с её порядковым номером, начиная с единицы. zip(brands, amounts) составляет пары из соответствующих элементов двух списков. По умолчанию перебор заканчивается, как только исчерпан более короткий список2.

Когда заканчивается цикл while

Перед каждой итерацией цикл while проверяет условие. Это удобно, когда число повторений заранее неизвестно. Например, можно запрашивать страницы API, пока очередная страница содержит данные. Проверьте, при каком условии цикл закончится. Команда break сразу завершает ближайший цикл, а continue пропускает оставшуюся часть текущей итерации1.

В примере ниже программа складывает суммы заказов из урока 1.1, пока не наберётся 5 000 ₽ или не закончатся заказы. Первые четыре заказа дают 4 990 ₽. До цели не хватает 10 ₽, поэтому цикл учитывает и пятый заказ.

02Как посчитать выручку по брендам

В уроке 1.1 мы складывали суммы пяти заказов. Теперь в каждой строке выгрузки есть бренд, сумма и статус заказа. Название одного бренда встречается в разных вариантах, например «BRISA», «brisa» и «Brisa » с пробелом в конце. Для отчёта нужно отобрать оплаченные заказы и привести названия к общему виду.

В Excel для такой задачи можно отфильтровать заказы по статусу, скопировать формулу очистки на весь столбец и собрать сводную таблицу. Анимация показывает, что произойдёт, если в Python скопировать проверку восемь раз. Когда появится девятый заказ, программа его пропустит.

Цикл возьмёт из выгрузки все строки, сколько бы их ни было. Для каждого бренда сложим суммы прошедших проверку заказов. Такой итог по группе называют агрегатом.

03Как написать и вызвать функцию

Чтобы определить функцию, напишите def, имя функции, а в скобках — её параметры. Затем с отступом запишите действия, которые нужно выполнить при вызове. В выражении clean_brand(" lumo") строка — аргумент, то есть значение, которое получит параметр функции. Инструкция return завершает вызов и возвращает результат. Если выполнение дойдёт до конца обычной функции без return, результатом будет None.

Зададим параметру значение по умолчанию в определении функции: def clean_brand(name, default="Без бренда"):. При вызове clean_brand(raw) параметр default получит строку "Без бренда". Чтобы выбрать другую замену для пустого названия, передайте значение по имени, например clean_brand(raw, default="—").

Функция может вернуть сразу несколько результатов в кортеже. Например, return len(paid), sum(paid) вернёт число оплаченных заказов и их общую сумму. Присваивание n, total = paid_stats(rows) запишет эти значения в две переменные. Такую операцию называют распаковкой.

Какие переменные доступны внутри функции

При каждом вызове функции параметры и локальные переменные получают свои значения. Имена этих переменных принадлежат локальной области видимости. Из функции можно обращаться и к глобальным именам, например к переменной, которую вы определили в отдельной ячейке ноутбука. Если внутри функции присвоить значение имени без объявления global или nonlocal, Python будет считать это имя локальным7.

Когда функция получает выгрузку через параметр rows, по записи вызова видно, какие данные она обработает. Если функция обращается к глобальной переменной, результат зависит ещё и от того, какое значение осталось в памяти после предыдущих запусков ячеек.

04Как собрать список или словарь одним выражением

Списковое включение (list comprehension) создаёт новый список. Выражение [row["amount"] for row in rows if row["status"] == "paid"] перебирает заказы, выбирает оплаченные и добавляет в список сумму каждого из них. Тот же список получается в цикле из анимации2.

Начните чтение с for row in rows, затем прочитайте условие после if. Когда оно истинно, Python вычисляет выражение в начале записи. В примере это row["amount"]. В словарном включении (dict comprehension) для каждого элемента записывают ключ и значение в фигурных скобках. Выражение {brand: round(s / total * 100) for brand, s in totals.items()} создаёт словарь, где ключ — название бренда, а значение — его доля в выручке в целых процентах.

Когда удобнее написать обычный цикл

Иногда явный цикл легче читать или отлаживать. Вот четыре примера.

  • Вложенные циклы. В выражении [x for day in days for x in day if x] сначала перебираются дни, затем значения для каждого дня. Два уровня отступов в обычном цикле наглядно показывают этот порядок.
  • Два условия с разными задачами. В выражении [a if a > 0 else 0 for a in amounts if a is not None] последнее условие отбирает элементы. Условное выражение в начале задаёт, что попадёт в список после отбора.
  • Нужно выполнить действие. Если цель — напечатать строки отчёта или записать их в файл, обычный цикл справится без создания лишнего списка. Например, [print(x) for x in rows] сохранит в списке значения None, которые возвращает print.
  • Нужно проверить промежуточный результат. В обычном цикле можно остановиться после append и посмотреть, что уже есть в списке. На примере ниже эту разницу видно в отладчике.

Попробуйте объяснить выражение коллеге. Если порядок действий трудно восстановить, запишите их отдельными строками цикла.

05Что происходит при вызове функции

Трассировка позволяет проследить выполнение программы по шагам. Видно, какую строку кода Python собирается выполнить, какие значения доступны в этот момент и из какой функции вызвали текущую. На этом принципе работает Python Tutor8. Для интерактива ниже события вызова, выполнения строк и возврата записаны в Python 3.13 с помощью sys.settrace9.

У каждого вызова функции есть кадр с параметрами и локальными переменными. Незавершённые вызовы образуют стек вызовов. В интерактиве текущий кадр показан сверху. Когда paid_brands вызывает clean_brand, сверху появляется новый кадр. Когда clean_brand возвращает результат, выполнение продолжается в paid_brands6. Попробуйте предсказать, какие имена увидите в кадре clean_brand.

Переключите интерактив на списковое включение. Сравните число вызовов clean_brand и результат обеих версий. В CPython начиная с версии 3.12 такое включение выполняется в кадре окружающей функции. При этом переменная row за пределами включения сохраняет прежнее значение, если оно было10. Пока включение работает, строящийся список недоступен по имени.

Рекурсия при обходе каталога

Функция может вызвать себя. Такой приём называют рекурсией. У каждого нового вызова свой кадр с параметрами. В каталоге магазина один и тот же порядок действий применим и ко всему каталогу, и к каждому подразделу.

Чтобы обход закончился, предусмотрим базовый случай, при котором функция сразу возвращает ответ6. В нашем каталоге это число товаров в разделе без подразделов. Если цепочка вложенных вызовов слишком длинная, Python выдаёт RecursionError. Текущий предел глубины можно узнать с помощью sys.getrecursionlimit(). В среде этого урока он равен 1 0009.

06Значения по умолчанию, переменные цикла и ранний выход

Список в качестве значения по умолчанию. Python вычисляет значение по умолчанию один раз при выполнении def1. Если написать def f(x, acc=[]): и внутри вызвать acc.append(x), вызовы без аргумента acc будут изменять один и тот же список. Чтобы каждый раз начинать с пустого списка, задайте acc=None и создайте список внутри функции, когда acc is None.

Переменная после цикла. Если цикл for row in rows сделал хотя бы одну итерацию, после него имя row по-прежнему указывает на последнюю обработанную строку5. При пустой выгрузке цикл ничего не присвоит. Если до цикла переменная уже существовала, её значение сохранится. Переменная перебора внутри спискового включения действует только в самом включении.

Несколько проверок внутри функции. Сначала можно проверить особые случаи и для каждого сразу вернуть результат. Такой приём называют ранним выходом. После этих проверок основной расчёт остаётся на одном уровне отступа в теле функции.

07Когда в pandas можно обойтись без цикла по строкам

В pandas многие задачи можно решить операцией сразу над всем столбцом. Такой подход называют векторизацией. Например, чтобы выбрать оплаченные заказы, достаточно сравнить весь столбец статусов со значением "paid". При обходе через df.iterrows() pandas создаёт отдельный объект Series для каждой строки. Документация рекомендует по возможности пользоваться операциями над столбцами, поскольку перебор строк обычно медленнее11.

08Три примера обработки выгрузок

В первом примере функция clean_brand исправляет написание названий. Цикл отбирает оплаченные заказы и суммирует выручку по каждому бренду. Затем словарное включение вычисляет долю каждого бренда в общей выручке.

Во втором примере в папке exports вместе с ежедневными выгрузками заказов лежат файлы возвратов, таблицы Excel и README. Списковое включение отбирает нужные CSV-файлы. Затем из имени каждого файла извлекаем дату с помощью среза из урока 1.2 и строим словарь, по которому можно найти файл за нужный день.

В третьем примере функция с инструкцией yield читает заказы по одному. При вызове она возвращает генератор. Это разновидность итератора, у которого можно запросить следующее значение с помощью next()3. Тело функции начнёт выполняться при первом таком запросе. После yield выполнение приостанавливается и может продолжиться при следующем запросе. Выражение вида (row["amount"] for row in rows) тоже создаёт генератор. При переборе ему не нужен промежуточный список всех сумм.

В учебном CSV-файле миллион строк. В примере оба способа чтения дают один и тот же итог. Пиковый объём выделенной памяти по замеру tracemalloc составил около 360 МБ при загрузке строк в список и 0,03 МБ при обработке генератором.
