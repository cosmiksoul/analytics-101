Интерактив в Plotly

На графике выручки пять цветных линий. Как узнать, сколько магазин заработал через приложение в июле, и сравнить результат с июньским? В этом уроке вы построите график с подсказками в plotly.express, используя таблицу в длинном формате. Затем подготовите две версии графика — интерактивную для менеджеров и картинку для письма директору.

01Как читатель может работать с графиком

Фигура Plotly описывает, какие данные показать и как оформить график. Каждый ряд данных хранится в отдельной трассе. Python передаёт это описание в формате JSON библиотеке plotly.js, которая строит график в браузере. С помощью JavaScript браузер показывает значения при наведении, скрывает выбранную линию или меняет масштаб. Если график вставить в письмо как изображение, ключевые числа стоит подписать прямо на нём.

Переключайте шаги кнопками или стрелками ← и → на клавиатуре. В анимации показано, как выглядят подсказки, выбор каналов и изменение масштаба в Plotly.

Что хранится в фигуре Plotly

В Python график представлен объектом go.Figure. Метод fig.to_dict() возвращает его описание в виде словаря2. В разделе data перечислены трассы. Например, у линии выручки есть тип scatter, название канала для легенды, массив месяцев x и массив значений y. В layout хранятся настройки заголовка, осей и легенды. У анимированной фигуры есть ещё frames с описаниями кадров.

Когда вы открываете сохранённый HTML-файл, браузер строит график по этому описанию. Если вы спрячете линию или увеличите участок, изменится вид графика в браузере. В исходном объекте Python сохранятся прежние настройки.

Как связаны plotly.express и graph_objects

Функция plotly.express (сокращённо px) строит график из таблицы. Например, в px.line можно указать столбцы для двух осей и столбец с названиями каналов. Для каждого канала получится отдельная линия. Функции px используют классы из graph_objects (go) и возвращают объект go.Figure1. Чтобы изменить подписи или добавить пояснение, у готовой фигуры можно вызвать update_traces, update_layout или add_annotation.

Как подготовить таблицу для px

В длинной таблице каждая строка соответствует одному наблюдению, а каждый столбец — одной переменной4. В учебном файле sales_monthly.csv строка показывает выручку одного канала в одной стране за месяц. Столбцы называются month, channel, country и revenue. В примере мы сложим выручку по странам и укажем color="channel", чтобы разделить линии по каналам.

Функция px.line принимает и широкую таблицу, в которой выручка каждого канала записана в отдельном столбце. Plotly преобразует её в длинную и по умолчанию использует подписи variable и value3. Их можно заменить через labels. В длинной таблице проще указать, что именно обозначает цвет, по какому столбцу разделить график на панели и по какому переключать кадры.

Подсказки, масштаб и выбор серий

Наведите курсор на линию выручки7. В подсказке появится значение у ближайшей точки. Текст задаёт hovertemplate. Например, %{y:.2f} подставляет значение по оси Y с двумя знаками после запятой. Если указать hovermode="x unified", в одной подсказке появятся значения всех видимых каналов за выбранный месяц5.

По умолчанию один щелчок по названию канала в легенде скрывает его линию, повторный — возвращает. Двойной щелчок оставляет только выбранный канал5. При автоматическом масштабе диапазон оси Y меняется с учётом видимых линий. Чтобы рассмотреть участок подробнее, выделите его мышью в режиме увеличения. Масштаб можно сбросить на панели инструментов. Там же можно переключиться на перемещение графика или сохранить текущий вид в PNG.

Анимация по времени

Если в px.bar указать animation_frame="month", у каждого месяца будет свой кадр. Кнопки запускают и приостанавливают показ, а ползунок позволяет выбрать месяц6. В июньском кадре хорошо видно, как выросла выручка приложения по сравнению с маем. Чтобы одинаковая высота столбца во всех кадрах означала одинаковую сумму, задайте общий диапазон оси Y. Для сравнения сразу нескольких месяцев удобнее расположить графики рядом, как в уроке 8.2.

Как сохранить график в HTML или в виде изображения

По умолчанию fig.write_html() сохраняет график в самодостаточный HTML — данные и библиотека для отображения находятся в одном файле. Коллеге достаточно открыть его в браузере. Параметр include_plotlyjs определяет, как подключать библиотеку7. В нашем примере файл с True занимает около 4,6 МБ. При значении "cdn" остаётся около 21 КБ, зато при первом открытии файла браузеру понадобится интернет, чтобы загрузить библиотеку из CDN.

Метод fig.write_image() сохраняет объект Python в виде изображения. Для статического экспорта Plotly использует Kaleido. Начиная с версии 1.0 этому пакету нужен установленный Chrome или Chromium8. PNG состоит из пикселей, а в SVG и PDF линии и текст нашего графика сохраняются в векторном виде и остаются чёткими при увеличении9. Изменения, которые читатель внёс в отдельно открытом HTML, в этот экспорт не попадут.

Как выбрать формат для читателя

Клаус Уилке различает исследование данных и представление результатов9. Если менеджеру нужно найти выручку своего канала за конкретный месяц, пригодятся подсказки и выбор отдельных линий. Для слайда или печатного отчёта точные значения придётся подписать. Вывод в заголовке полезен в обоих случаях — он помогает понять график ещё до первого щелчка.

02Один график для менеджеров и директора

Коммерческий директор хочет узнать, как менялась выручка по каналам продаж в 2024–2025 годах. В учебной выгрузке sales_monthly.csv 960 строк за 24 месяца, десять каналов и четыре страны. Для графика возьмём пять крупнейших каналов по выручке за 2025 год. Вместе они принесли около 81% годовой выручки.

Менеджерам нужно сравнить помесячные показатели своих каналов в браузере. Директор прочитает краткий итог в письме на телефоне. Подготовим для каждого подходящую версию графика.

На первом графике можно навести курсор на точку, скрыть линию или выделить период мышью. Этот учебный пример воспроизводит основные действия в Plotly. На втором графике сразу подписаны каналы и два значения выручки приложения, отмечен месяц выпуска новой версии. Сначала ответьте на вопрос ниже, затем сравните обе версии в пяти ситуациях.

04Размер HTML, подписи и просмотр на телефоне

Три примера ниже можно повторить в ноутбуке из раздела «Материалы». В первом проверим размер файла на случайных точках. В остальных вернёмся к выручке каналов.

Данные остаются в HTML. Параметр include_plotlyjs="cdn" позволяет вынести библиотеку в отдельный файл. Координаты точек остаются внутри. В нашем примере HTML с тысячей точек занимает около 35 КБ, с миллионом — около 26 МБ. Если передать в px.scatter более тысячи точек с настройками по умолчанию, функция выберет трассу scattergl. Она использует WebGL для отрисовки, но сохраняет координаты всех точек. Для графика месячных итогов достаточно передать суммы по месяцам.

Какие числа останутся на картинке? У пяти линий по 24 точки. В подсказках можно узнать все 120 значений выручки, но на экспортированном графике ни одно из них по умолчанию не подписано у точки. Вынесем изменение выручки в заголовок-вывод10 и отметим на графике месяц выпуска новой версии приложения. Заголовкам посвящён урок 8.4.

Как прочитать график на телефоне. Перенесите легенду под график, чтобы оставить больше места для линий. Если вертикальный жест меняет масштаб и мешает листать страницу, отключите перетаскивание с помощью dragmode=False. Добавьте текстовую альтернативу — краткое описание вывода и таблицу с точными значениями. WCAG 2.2 предусматривает текстовые альтернативы для нетекстового содержимого и доступ к функциям с клавиатуры11. На телефоне и с клавиатуры график стоит проверить отдельно.

05Когда для работы с графиком нужно приложение

В одной фигуре Plotly можно добавить кнопки, списки и несколько областей построения. Для задач посложнее, например когда выбор клиента должен запустить запрос к базе и обновить несколько графиков, удобно собрать приложение. В Python для этого используют Dash и Streamlit12. О проектировании дашбордов подробнее в теме 06 блока BI.

06График каналов от таблицы до файла

В первом примере groupby складывает выручку по странам для каждой пары «месяц и канал». Из полученной таблицы px.line строит график пяти каналов. Это те же данные, что в уроке 8.1. Четыре примера этого раздела выполняются по порядку в одном сеансе Python.

Второй пример меняет текст подсказки. Параметр custom_data передаёт для каждой точки месяц словами и долю канала в общей выручке магазина за месяц. Шаблон %{y:.2f} выводит сумму с двумя знаками после запятой, а %{customdata[1]:.0%} — долю в целых процентах. Пустой тег <extra></extra> убирает дополнительную подпись с именем линии5. В separators=", " первый символ задаёт десятичную запятую, второй — пробел между разрядами.

Третий пример строит анимированную столбчатую диаграмму. Во всех 24 кадрах шкала одна — от 0 до 11 млн ₽.

Четвёртый пример сохраняет линейный график в пяти файлах — двух вариантах HTML, JSON, PNG и SVG — и выводит их размеры.
