Векторы и матрицы в NumPy

Кто из тысячи покупателей больше всего похож на клиента 49 по возрасту, доходу и числу заказов? Представим каждого покупателя как вектор, а таблицу с тремя признаками — как матрицу. В NumPy вы найдёте ближайших клиентов, сравните результаты до и после стандартизации и разберёте, как скалярное произведение помогает рассчитать прогноз для каждого клиента.

01Как представить данные о клиентах в виде векторов

Возраст, доход и число заказов — три признака клиента. Три значения определяют положение точки в пространстве, где у каждого признака своя ось. Вектор клиента можно изобразить стрелкой из начала координат в эту точку. Расстояние между точками показывает, насколько различаются значения признаков, а угол между стрелками позволяет сравнить их направления. Оба показателя зависят от выбора единиц. Посмотрим, что изменится, если привести все три признака к общей шкале.

Переключайте шаги кнопками или стрелками ← и → на клавиатуре. На экране показана проекция, а значения над графиком рассчитаны по всем трём координатам.

Вектор: точка и стрелка

Клиенту 49 из учебной таблицы 57 лет. Его месячный доход — 118 000 ₽, за квартал он сделал 6 заказов. Эти числа образуют вектор (57, 118 000, 6), если записывать признаки в одном и том же порядке для всех клиентов. Каждое число — координата вектора. Координаты задают положение точки. Чтобы показать длину и направление вектора, проведём стрелку из начала координат до этой точки1.

Для пятидесяти признаков понадобилось бы пятьдесят осей. На плоском графике видна лишь проекция, но NumPy вычислит длину вектора и угол между двумя такими векторами по тем же формулам.

Длина и расстояние

Длина вектора в евклидовом пространстве равна корню из суммы квадратов его координат. Для двух координат это знакомая теорема Пифагора. Чтобы найти расстояние между двумя точками, вычислим разности соответствующих координат и найдём длину получившегося вектора3.

‖a‖ = √(a1² + a2² + … + an²)
‖a − b‖ = √((a1 − b1)² + … + (an − bn)²)Векторы a и b описывают двух клиентов. У каждого n признаков. Например, ai — значение признака с номером i у первого клиента. Знак ‖·‖ обозначает длину вектора.

В исходных единицах длина вектора клиента 49 равна √(57² + 118 000² + 6²) ≈ 118 000,01. На квадрат дохода приходится 99,99998% суммы под корнем. Поэтому в этом примере длина почти совпадает с численным значением дохода в рублях.

Скалярное произведение и косинус

Для скалярного произведения перемножают соответствующие координаты двух векторов и складывают результаты. Ту же величину можно получить из геометрии, умножив длины векторов на косинус угла между ними23.

a · b = a1b1 + a2b2 + … + anbn = ‖a‖ · ‖b‖ · cos θθ — угол между ненулевыми векторами a и b. Косинус равен 1, если стрелки направлены в одну сторону, 0 при прямом угле и −1 при противоположных направлениях.

При неизменных длинах векторов скалярное произведение растёт, когда угол между ними уменьшается. Для ненулевых векторов знак указывает на тип угла. Положительное значение соответствует углу меньше 90°, отрицательное — больше 90°. Если скалярное произведение равно нулю, векторы перпендикулярны. Чтобы сравнить направления независимо от длин, скалярное произведение делят на произведение длин. Так получают косинусную близость.

cos θ = a · b / (‖a‖ · ‖b‖)Косинус принимает значения от −1 до 1. Если умножить все координаты одного вектора на одно и то же положительное число, косинус сохранится. Для нулевого вектора он не определён.

В разделе «Код» мы сравним покупки двух товаров. Если каждого товара покупает одна и та же группа людей и количества покупок по клиентам пропорциональны, косинус равен 1, даже если одного товара продаётся вдвое больше.

Матрица признаков и прогноз для каждого клиента

В матрице X — 1 000 строк и 3 столбца. Строка X[i] содержит признаки одного клиента, а столбец X[:, j] — значения одного признака у всех клиентов6.

Для расчёта прогноза нам понадобится умножение матрицы на вектор весов. В NumPy его записывают оператором @. Пусть у матрицы X форма (n, d), а у вектора w — (d,). Тогда выражение X @ w даёт n чисел, по одному для каждой строки матрицы8.

(X @ w)i = xi1w1 + xi2w2 + … + xidwd = xi · wxij — значение признака j у объекта i, а wj — вес этого признака. В позиции i результата стоит скалярное произведение строки xi и вектора w.

В нашем примере прогноз квартальных трат равен 205 + 0,0347 · доход + 2 550 · число заказов. Для каждого клиента запишем в строку матрицы X1 единицу, месячный доход и число заказов за квартал. Единица нужна для постоянного слагаемого 205. Выражение X1 @ w рассчитает прогнозы для всех клиентов. В уроке 4.2 вы подберёте веса по данным.

NumPy: ndarray, shape, dtype

В NumPy для хранения матрицы используют ndarray — массив, у которого все элементы одного типа4. Форма массива (shape) указывает число элементов вдоль каждой оси. У матрицы клиентов форма (1000, 3), у отдельной строки — (3,). Атрибут dtype указывает тип элементов. В нашем примере исходные данные имеют целочисленный тип int64, а после стандартизации получаются числа типа float64.

Ось — одно из измерений массива. Вызов X.mean(axis=0) усредняет значения каждого столбца по всем клиентам. Получаются три средних, по одному на признак. Вызов X.mean(axis=1) усредняет значения внутри каждой строки. Целый индекс X[48] выбирает строку клиента 49, поскольку отсчёт начинается с нуля. Срез : в записи X[:, 1] выбирает все строки столбца дохода, а X[:3, 1] — доходы первых трёх клиентов.

Векторизация и broadcasting

Векторизация позволяет записать вычисление сразу для всего массива. Например, X - X.mean(axis=0) вычитает из каждого значения среднее по его столбцу. NumPy выполняет эту операцию в скомпилированном коде, поэтому писать цикл на Python для обхода 3 000 элементов не требуется.

За совмещение форм отвечает broadcasting5. NumPy сравнивает размеры осей справа налево. Два размера совместимы, если они равны или хотя бы один равен 1. Недостающие оси слева тоже считаются осями размера 1. Например, при вычитании из матрицы формы (1000, 3) вектора формы (3,) NumPy использует один и тот же вектор для каждой строки.

СлеваСправаРезультат
(1000, 3)(3,)(1000, 3): из каждой строки вычли один вектор
(6, 1, 3)(1, 6, 3)(6, 6, 3): разности всех пар из шести клиентов
(3,)(3, 1)(3, 3): строка и столбец дали таблицу
(1000, 3)(1000,)ошибка: 3 и 1 000 не равны, и ни одна не 1

Во второй строке таблицы результат хранит три разности координат для каждой пары. Чтобы получить расстояния, нужно возвести разности в квадрат, сложить их по последней оси и извлечь корень. В разделе «Нюансы» разберём, как сочетание одномерного массива и столбца влияет на форму результата.

Почему признаки масштабируют

В квадрат расстояния входят квадраты разностей по каждому признаку. Разница в 40 лет даёт слагаемое 1 600, а разница в 40 000 ₽ — 1,6 млрд. Если у двух клиентов доходы совпадают, расстояние зависит только от возраста и числа заказов. Но при заметной разнице доходов именно она определяет почти всё расстояние. Та же проблема возникает с углами. Для любой пары из нашей тысячи клиентов угол между векторами в исходных единицах меньше 0,15°.

Чтобы сравнить отклонения по разным признакам, применим стандартизацию. Из каждого значения вычтем среднее по его столбцу и разделим разность на стандартное отклонение того же столбца.

z = (x − μ) / σx — исходное значение, μ — среднее по столбцу, σ — стандартное отклонение по всем клиентам. Здесь σ равно корню из среднего квадрата отклонений от μ. Для возраста это 15,5 года, для дохода — 38 232 ₽.

Теперь координата показывает, на сколько стандартных отклонений значение выше или ниже среднего. В начале координат все три признака равны своим средним. До стандартизации угол между векторами клиентов 49 и 881 составлял всего 0,04°, а после — около 158°. У первого клиента все три показателя выше среднего, у второго — ниже.

02Как найти похожих клиентов и спрогнозировать траты

В файле data/clients/clients.csv собраны данные о тысяче вымышленных клиентов интернет-магазина. Для каждого известны возраст, месячный доход, число заказов и траты за квартал. Решим на этих данных две задачи.

Маркетолог хочет показать рекламу клиентам, похожим на клиента 49. Найдём трёх ближайших к нему покупателей по возрасту, доходу и числу заказов. Для этого выберем шкалу признаков и вычислим расстояния между векторами клиентов.

Вторая задача — проверить прогноз трат. Разберём выражение pred = X1 @ w из ноутбука коллеги. Какие числа перемножаются для каждого клиента? Сколько прогнозов получится и как сопоставить каждый из них с фактическими тратами?

03Как расстояние и угол зависят от шкалы признаков

Оставим два признака, чтобы показать клиентов на плоскости. По горизонтали отложим месячный доход, по вертикали — возраст. Серые точки соответствуют тысяче клиентов из таблицы. Две точки, A и B, можно перемещать. В исходных единицах стрелки начинаются в точке (0, 0), после стандартизации — в точке со средними значениями дохода и возраста.

В начальном положении A соответствует клиенту 175 (26 лет, 116 000 ₽), B — клиенту 15 (64 года, 60 000 ₽). Прежде чем двигать точки, попробуйте предсказать результат.

В исходных единицах задайте обоим клиентам одинаковый возраст, сохранив их исходные доходы. Расстояние уменьшится с 56 000,01 до 56 000. На основном графике оси растянуты по-разному. На вставке один рубль и один год занимают одинаковую длину. При исходных значениях угол между стрелками там всего 0,05°.

Нажмите «Сбросить» и включите стандартизацию. Теперь единица на каждой оси соответствует одному стандартному отклонению, и по рисунку можно судить об угле между векторами. Для A и B косинус близок к −0,95. Клиент A моложе среднего и получает больше среднего, а клиент B старше среднего и получает меньше.

04Формы массивов и типы элементов

Одномерный массив и столбец. У массива формы (5,) одна ось. При транспонировании .T его форма остаётся прежней. Массив формы (5, 1) имеет пять строк и один столбец. Целый индекс в X[:5, 0] убирает ось столбцов. Список индексов в X[:5, [0]] и срез в X[:5, 0:1] сохраняют её. Чтобы превратить одномерный массив в столбец, используйте reshape(-1, 1) или [:, None].

Как вместо тысячи ошибок прогноза получить миллион разностей. Если фактические траты имеют форму (1000,), а прогнозы — (1000, 1), NumPy сопоставит прогноз каждого клиента с тратами всех клиентов. Среднее абсолютное значение по миллиону разностей составит 7 532 ₽. Если вернуть прогнозам форму (1000,), в каждой паре окажутся прогноз и фактические траты одного клиента. Средняя абсолютная ошибка в этом случае равна 3 017 ₽.

Что можно записать в целочисленный массив. В нашем примере у массива тип int64. При присваивании числа с дробной частью NumPy отбросит эту часть. Выражение X - X.mean(axis=0) создаёт новый массив типа float64. При записи результата в исходный массив через -= NumPy выдаст ошибку преобразования типа. Ещё одно ограничение — переполнение. Квадрат числа 80 500 выходит за пределы int32, поэтому в этом примере результат умножения оказывается отрицательным7. Для этих целых массивов / даёт вещественное частное, а // округляет частное вниз.

05Почему в многомерных данных труднее различать расстояния

В пространстве с большим числом независимых признаков расстояния от одной точки до остальных могут мало различаться относительно их величины. Это одно из проявлений проклятия размерности69. Посмотрим на модельный пример. В каждой строке таблицы мы взяли тысячу случайных точек и ещё одну точку для сравнения. Каждую координату независимо сгенерировали из стандартного нормального распределения. В последнем столбце указана доля векторов, почти перпендикулярных вектору точки сравнения.

06Код: массивы, расстояния, косинус

Первый пример показывает, как создать вектор и матрицу, узнать их форму и тип, выбрать нужные строки и столбцы. В конце выражение X1 @ w рассчитывает прогноз трат. Здесь и далее приведён вывод для Python 3.13, NumPy 2.5.3 и pandas 3.0.5.

Во втором примере сравним шесть клиентов. Сначала получим массив разностей формы (6, 6, 3), затем посчитаем расстояния. Для тысячи клиентов одни только разности заняли бы 24 МБ. Поэтому используем формулу ‖a − b‖² = ‖a‖² + ‖b‖² − 2 a · b. Скалярные произведения всех пар даёт матрица Z @ Z.T. По косинусу между двумя столбцами можно судить о сходстве покупательских аудиторий с учётом количества покупок.
