Доверительные интервалы и бутстрэп

В недельном отчёте магазина средний чек составил 4 485 ₽. Насколько точна эта оценка? Вы построите доверительные интервалы для среднего чека и конверсии, а для медианы примените бутстрэп. На учебных данных проверите, как часто каждый метод даёт интервал, в который попадает истинное значение.

01Что означает уровень доверия 95%

Доверительный интервал задаёт диапазон значений параметра по одной выборке. Уровень доверия показывает, на какую частоту попаданий рассчитан метод. Если условия метода выполнены, при многократном повторении примерно 95 из 100 интервалов уровня 95% будут содержать истинное значение. Для среднего и доли мы рассчитаем границы по формулам. Для медианы возьмём из исходной выборки повторные выборки с возвращением и посмотрим, как меняется результат.

Как проверить метод на повторных выборках

Пока мы не взяли выборку, границы интервала L и U — случайные величины. Они зависят от того, какие наблюдения попадут в выборку. Для метода с точным покрытием 95% выполняется равенство1.

P(L ≤ θ ≤ U) = 1 − α = 0,95θ — истинное значение, например среднее совокупности μ · L и U — границы, вычисленные по выборке · α = 0,05 — заданная вероятность того, что интервал не включит параметр

После расчёта границы фиксированы. Например, интервал от 9,22 до 16,35 дня содержит известное нам среднее 11,92 дня. Вероятность того, что интервал из новой случайной выборки будет содержать параметр, называют покрытием. Её можно оценить в симуляции. В нашем примере из 10 000 интервалов с заявленным уровнем 95% истинное среднее содержали 92,7%.

Интервал для среднего: ЦПТ и t

Центральная предельная теорема из урока 5.3 объясняет, почему на больших выборках распределение среднего x̄ приближается к нормальному. При независимых наблюдениях стандартная ошибка среднего равна σ/√n. Если σ известно, приближённый интервал уровня 95% равен x̄ ± 1,96·σ/√n. На практике σ обычно заменяют выборочным стандартным отклонением s. Уильям Госсет, писавший под псевдонимом Student2, показал, что для независимых наблюдений из нормального распределения отношение (x̄ − μ)/(s/√n) имеет t-распределение с n − 1 степенями свободы. У этого распределения более тяжёлые хвосты, поэтому множитель для интервала больше 1,96.

x̄ ± tn−1; 0,975 · s/√nx̄ — среднее выборки · s — её стандартное отклонение с делителем n − 1 · s/√n — оценка стандартной ошибки · tn−1; 0,975 — квантиль t-распределения уровня 0,975; для 99% берут 0,995

Интервалы Вальда и Вилсона для доли

Обозначим визит с покупкой единицей, а без покупки — нулём. Конверсия равна среднему этих значений. Если воспользоваться нормальным приближением, получится интервал Вальда1.

p̂ ± z · √(p̂(1 − p̂) / n)p̂ — доля в выборке · n — число визитов · z = 1,96 для 95%

При двух покупках за 100 визитов формула даёт от −0,74 до 4,74%, хотя отрицательная конверсия невозможна. Если покупок не было, обе границы окажутся равны нулю. Причина в том, что стандартную ошибку оценивают по наблюдаемой доле p̂, а при редких покупках эта оценка ненадёжна. Интервал Вилсона включает все значения p, для которых расстояние от p̂ до p не превышает z·√(p(1 − p)/n)3.

(p̂ + z²/2n ± z·√(p̂(1 − p̂)/n + z²/4n²)) / (1 + z²/n)те же p̂, n и z · центр сдвинут от p̂ к 1/2 · границы не выходят из [0; 1]

При двух покупках за 100 визитов интервал Вилсона составляет 0,55–7,00%. В симуляции из раздела «Код» при истинной конверсии около 3,4% и n = 100 интервал Вальда включал её в 85,0% выборок, а интервал Вилсона — в 94,4%. Браун, Кай и Дасгупта рекомендуют метод Вилсона как один из вариантов для небольших выборок3.

Как бутстрэп оценивает разброс

Для медианы, квантилей и метрик-отношений, например выручки на визит, бывает трудно выбрать формулу стандартной ошибки. Бутстрэп, предложенный Брэдли Эфроном, позволяет оценить разброс по имеющимся наблюдениям4. Вот как построить процентильный интервал.

  1. Из выборки размера n взять n значений с возвращением: одно попадёт несколько раз, другое ни разу.
  2. Посчитать на этой перевыборке нужную статистику: среднее, медиану, 90-й перцентиль.
  3. Повторить B раз, обычно B = 1 000–10 000.
  4. Взять 2,5-й и 97,5-й перцентили B значений — это процентильный интервал 95%.

Стандартное отклонение результатов по B перевыборкам служит оценкой стандартной ошибки, а на гистограмме видно, симметрично ли их распределение5. В анимации интервал для среднего составил 9,57–16,26 дня по бутстрэпу и 9,22–16,35 дня по t-формуле. Для медианы выборки 8,02 дня получился интервал 5,59–13,19 дня. Если метрика — отношение двух сумм, при каждом повторе заново выбирают целые единицы наблюдения со всеми их показателями. Например, для выручки на визит выручку выбранных посетителей делят на общее число их визитов6.

Ширина и размер выборки

Половину ширины симметричного интервала называют предельной погрешностью. В записи «4 485 ± 667 ₽» она равна 667 ₽. При фиксированном уровне доверия и сходном разбросе данных ширина приблизительно пропорциональна 1/√n. Чтобы сократить погрешность вдвое, нужно примерно вчетверо больше независимых наблюдений. Отсюда можно оценить необходимый размер выборки для погрешности E.

n = (z·σ / E)²,  для доли  n = z²·p(1 − p) / E²σ и p берут из прошлых данных · E — допустимая погрешность · z = 1,96 для 95%

Средний чек с погрешностью ±200 ₽ при σ ≈ 5 400 ₽ требует (1,96 · 5 400 / 200)² ≈ 2 800 чеков — около 10 недель продаж. Конверсия 3,4% с погрешностью ±0,5 п. п. — около 5 050 визитов.

02Как указать неопределённость в недельном отчёте

В недельный отчёт учебного магазина вошли первые 270 чеков из checks.csv. Средний чек составил 4 485 ₽, медиана — 3 195 ₽. По первым 8 000 визитам из visits.csv конверсия составила 3,24%. Отдельно отобрали первые 100 визитов из органического канала. В двух из них посетители совершили покупку.

Подберите интервал для каждого из четырёх показателей. Как объяснить руководителю, что означают полученные границы? Для этой задачи считаем наблюдения независимыми, а первые строки файлов — выборкой, типичной для магазина.

03Сколько интервалов содержат истинное среднее

В интерактиве можно менять размер выборки, уровень доверия и способ расчёта. На выбор есть два набора данных. В order_gaps.csv среднее время между заказами — 11,92 дня. В checks.csv средний чек — 4 334 ₽, причём несколько крупных оптовых заказов сильно повышают среднее. Кнопка «Новая сотня» добавляет 100 выборок. Счётчик «всего» показывает долю интервалов, в которые не попало истинное среднее. В режиме «Бутстрэп» каждый интервал построен по 1 000 перевыборок, которые можно просматривать по очереди.

Генератор использует фиксированное начальное значение. Повторив те же действия, вы получите те же выборки. В разделе «Код» используется другой генератор, поэтому конкретные интервалы различаются. Похожий эксперимент можно провести в Seeing Theory7.

Что видно в интерактиве

Сколько промахов ожидать. В первой сотне для времени между заказами при n = 40 и уровне 95% получилось девять промахов. Для анимации специально выбрана серия с пятью промахами. В других сериях их бывало и девять, и двенадцать. За 2 000 интервалов при n = 40 доля промахов составила 7,0%, при n = 400 — 5,8%. Если при n = 40 повысить уровень до 99%, те же интервалы станут примерно на треть шире. В этом эксперименте промахов останется около 2%.

Суммы чеков. При n = 10 истинное среднее оказалось за границами 19,7% интервалов, при n = 40 — за границами 18,1%. Большинство таких интервалов лежит ниже μ. В небольшую выборку редко попадают оптовые заказы, поэтому и среднее, и стандартное отклонение часто занижены. При n = 400 доля промахов всё ещё равна 8,1%.

Бутстрэп для времени между заказами. При n = 10 процентильные интервалы короче интервалов Стьюдента. В симуляции бутстрэп дал 14,0% промахов, t-метод — 10,1%. При n = 40 разница в ширине интервалов меньше.

Ответ на задачу

Для среднего чека 4 485 ₽ t-интервал уровня 95% составляет 3 818–5 152 ₽. Для медианы 3 195 ₽ бутстрэп дал 3 000–3 450 ₽. На этих данных второй интервал примерно втрое уже первого. Отдельные крупные покупки сильнее влияют на среднее, чем на медиану. При недельной конверсии 3,24% интервал Вилсона составляет 2,87–3,65%. Для органического канала при двух покупках за 100 визитов он заметно шире — 0,55–7,00%. Конверсия 3,4% совместима с этими данными.

В отчёте можно написать «Средний чек по 270 заказам составил 4 485 ₽. Доверительный интервал уровня 95% — от 3 818 до 5 152 ₽». Для методического примечания стоит добавить результат проверки. В 10 000 выборок по 270 чеков из этого магазина интервал содержал среднее всей совокупности примерно в 92% случаев. На этих данных точность метода ниже заявленной.

04Нюансы: формулировка, пересечение, малые выборки

95% относятся к способу построения интервала. После расчёта границы фиксированы. В учебном примере мы даже можем проверить, попал ли истинный средний чек в интервал от 3 818 до 5 152 ₽. Чтобы оценить покрытие, придётся повторять весь опыт с новыми выборками. В исследовании Хукстры и соавторов почти все опрошенные студенты и исследователи согласились хотя бы с одной ошибочной трактовкой доверительного интервала9.

Для сравнения каналов постройте интервал разности конверсий. По 1 500 визитам в каждом канале конверсия рассылки составила 5,67% (4,61–6,95%), а рекламы — 3,93% (3,06–5,04%). Интервалы пересекаются, хотя интервал для разности «рассылка минус реклама» целиком положителен — от 0,20 до 3,29 процентного пункта. При независимых группах складываются дисперсии оценок. Полуширина интервала разности здесь около 1,54 пункта, а сумма полуширин двух отдельных интервалов — 2,16 пункта10. О статистической значимости поговорим в уроке 6.3.

Какие наблюдения доступны бутстрэпу. Перевыборка может содержать только те значения, которые встречались в исходной выборке. Для десяти наблюдений времени между заказами средняя ширина бутстрэп-интервала составила 12,6 дня, t-интервала — 15,6 дня. Их покрытия в симуляции — 85,6% и 89,5% соответственно. При n = 40 разница в ширине меньше. Есть и другая причина ошибок. Если в выгрузку попали только чеки дешевле 15 000 ₽, бутстрэп даст для среднего интервал 3 251–3 803 ₽. Средний чек по полным данным, 4 334 ₽, лежит выше его верхней границы5.

05Ограничения: байесовские интервалы и зависимые данные

В этом уроке мы строили частотные интервалы. Байесовский интервал допускает вероятностную трактовку для уже полученных данных. Например, 95-процентному интервалу соответствует 95% апостериорной вероятности при выбранной модели и априорном распределении параметра. Подробнее об этом — в уроке 11.5.

Во всех примерах наблюдения считались независимыми. Если один пользователь совершил несколько визитов, результаты этих визитов могут быть связаны. Тогда можно случайно выбирать пользователей вместе со всеми их визитами. Если при положительной связи выбирать визиты по отдельности, интервал может получиться слишком узким. К выбору единицы наблюдения вернёмся в уроке 6.4.

06Код: statsmodels, бутстрэп и проверка покрытия

Первый пример вычисляет интервал среднего чека по 270 заказам двумя способами — по формуле с stats.t и с помощью DescrStatsW из statsmodels8.

Второй пример сравнивает интервалы Вальда и Вилсона для конверсии. Обе пары границ рассчитывает функция proportion_confint8.

Третий пример строит бутстрэп-интервал для медианы. Функция rng.integers выбирает индексы чеков сразу для B перевыборок. В таблице x[idx] размера B × n каждая строка соответствует одной перевыборке. Затем программа находит медиану каждой строки и сравнивает ручной расчёт с интервалами из scipy.stats.bootstrap, полученными процентильным методом и методом BCa11.

Четвёртый пример проверяет покрытие метода. Программа многократно берёт выборки из данных магазина и подсчитывает, в какой доле интервалов содержится известный параметр.
