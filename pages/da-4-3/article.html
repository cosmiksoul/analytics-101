Производная и градиент

Как подобрать веса модели, чтобы уменьшить значение функции потерь? Для одного веса направление подсказывает производная, для нескольких — градиент. На графике вы проверите, как размер шага влияет на результат. Затем обучите линейную регрессию из урока 4.2 градиентным спуском и сравните найденные веса с результатом lstsq.

01Как градиент помогает уменьшить ошибку

Функция потерь показывает, насколько предсказания модели при выбранных весах расходятся с данными. Если вес один, производная показывает, как изменится ошибка при небольшом увеличении веса. Если весов несколько, производные по каждому из них образуют вектор — градиент. Чтобы уменьшить ошибку, веса понемногу сдвигают в противоположном направлении. Величину сдвига регулирует шаг обучения. На графике с двумя долинами можно увидеть, как выбор шага влияет на скорость спуска, а выбор начальной точки — на то, в какой долине он закончится.

Переключайте шаги кнопками под анимацией или стрелками ← и → на клавиатуре.

Как связаны производная и наклон графика

Пусть ошибка L зависит от одного веса w. Проведём касательную к графику в точке с координатой w. Её наклон и есть производная L′(w). Она позволяет оценить, как изменится ошибка при небольшом изменении веса. Например, в анимации L′(−1,8) ≈ −3,88. Если увеличить вес на 0,01, ошибка уменьшится примерно на 0,039.

Чтобы вычислить наклон касательной, проведём прямую через две точки графика с координатами w и w + h по горизонтали. Такую прямую называют секущей. Её наклон равен разности значений функции, делённой на h. Когда h стремится к нулю, наклон секущей приближается к наклону касательной. Если этот предел существует, он равен производной1.

L′(w) = limh→0 (L(w + h) − L(w)) / hw — вес · h — изменение веса · дробь под знаком предела задаёт наклон секущей

Если производная положительна, небольшое увеличение веса увеличивает ошибку. Если производная отрицательна, ошибка уменьшается. При нулевой производной касательная горизонтальна.

Частные производные и градиент

В анимации и интерактиве у функции потерь два аргумента. Каждая пара весов задаёт точку на карте, а значение функции определяет высоту в этой точке.

L(w1, w2) = ¼(w12 − 1)2 + 0,15·w1 + 4w22 + 0,2Первое слагаемое при w1 = −1 и w1 = 1 равно нулю. Слагаемое 0,15·w1 делает левую долину глубже правой и слегка смещает оба минимума. Чем больше |w2|, тем выше поверхность.

Частная производная ∂L/∂w1 показывает, как меняется ошибка при изменении первого веса, если второй вес постоянен. Аналогично находят производную по второму весу. Градиент ∇L (читается «набла L») состоит из этих частных производных. В точке с ненулевым градиентом он указывает направление самого быстрого роста функции, а его длина равна скорости роста в этом направлении23. На карте градиент перпендикулярен линии уровня, которая проходит через эту точку.

∇L = (∂L/∂w1; ∂L/∂w2) = (w1(w12 − 1) + 0,15; 8w2)∂ — знак частной производной · в начальной точке (−1,8; 1) градиент приблизительно равен (−3,88; 8)

Цепное правило для квадрата ошибки

Рассмотрим модель с одним признаком x и одним весом w. Прогноз равен w·x. Его отклонение от известного ответа y обозначим через e, а потерю определим как L = e2. При изменении веса сначала меняется прогноз, а вместе с ним — e и L. По цепному правилу производную потери по весу можно получить, перемножив две производные2.

dL/dw = dL/de · de/dwe = w·x − y — ошибка прогноза · dL/de = 2e · de/dw = x · производная потери по весу равна 2e·x

Ниже мы применим это правило к средней потере по всем клиентам. В нейросетях производные вычисляют по тому же правилу, двигаясь от выходного слоя к входному. Этот алгоритм называется обратным распространением ошибки.

Что означает нулевая производная

Во внутренней точке минимума гладкой функции касательная горизонтальна. Для функции одной переменной это означает L′ = 0, для функции нескольких переменных — ∇L = 0. Такой же признак есть у максимума и у седловой точки. На карте седло находится примерно в точке (0,15; 0). Если пройти через неё вдоль w1, высота по обе стороны уменьшается. Вдоль w2 высота по обе стороны растёт.

Иногда минимум можно найти из уравнения ∇L = 0. Например, для L(x) = x2 уравнение 2x = 0 даёт x = 0. Для линейной регрессии такое условие называют нормальным уравнением. В уроке 4.2 мы решали задачу наименьших квадратов с помощью lstsq.

Градиентный спуск и шаг обучения

Для более сложной функции можно выбрать начальные веса, вычислить градиент и сделать шаг в противоположном направлении. Затем градиент вычисляют заново, уже в новой точке. Метод градиентного спуска предложил Огюстен Коши в 1847 году4. Для обучения моделей используют как сам метод, так и его варианты3.

wk+1 = wk − η·∇L(wk)wk — веса после k итераций · ∇L(wk) — градиент при этих весах · η («эта») — положительный множитель, который задаёт шаг обучения

Для параболы L = x2 обновление упрощается до x ← (1 − 2η)·x. Начнём с x > 0. При 0 < η < 0,5 значение x уменьшается и остаётся положительным. При η = 0,5 уже первый шаг даёт ноль. При 0,5 < η < 1 знак меняется после каждого шага, но расстояние до нуля сокращается. При η = 1 расстояние остаётся прежним, а при η > 1 растёт. В последнем случае спуск расходится.

Выпуклость и локальные минимумы

У выпуклой функции отрезок между любыми двумя точками графика лежит на графике или выше него. Любой её локальный минимум одновременно служит глобальным5. Например, на параболе x2 спуск с шагом 0,5 приводит к минимуму из любой начальной точки.

У учебной поверхности два минимума. В правой долине значение L ≈ 0,344, и во всех соседних точках оно выше. В левой долине значение меньше, L ≈ 0,045. Если начать справа и двигаться небольшими шагами против градиента, спуск остановится возле правого минимума.

Как приближённо вычислить интеграл

Для непрерывной неотрицательной функции интеграл на отрезке равен площади под графиком. Разобьём отрезок на n равных частей, построим над каждой прямоугольник и возьмём его высоту по значению функции в середине этой части. По мере увеличения n сумма площадей приближается к определённому интегралу1.

∫ab f(x) dx ≈ Σ f(xi)·Δxa, b — границы отрезка · xi — середина i-го интервала · Δx = (b − a) / n — ширина интервала · при n → ∞ сумма стремится к интегралу

Если f — плотность вероятности, площадь под её графиком на отрезке равна вероятности попасть в этот отрезок. Площадь под всем графиком равна единице2. Для наблюдений плотность можно оценить по гистограмме. В примере с доходами два соседних столбца вместе покрывают интервал от 50 000 до 100 000 ₽. Сумма площадей этих столбцов равна доле клиентов в интервале — 0,545. Верхнюю границу код исключает.

02Как найти коэффициенты линейной регрессии

В уроке 4.2 мы предсказывали квартальные траты клиента по его доходу и числу заказов. Модель имеет вид spend ≈ w0 + w1·income + w2·orders. На данных 1 000 клиентов из clients.csv функция np.linalg.lstsq нашла коэффициенты w ≈ [205; 0,0347; 2 550]6.

Теперь найдём те же коэффициенты градиентным спуском. Результат lstsq пригодится для проверки. С нейросетью такой возможности обычно нет, поэтому особенно важно уметь проверить градиент и увидеть, уменьшаются ли потери.

Сначала попробуем разные шаги на карте с двумя долинами. Затем вернёмся к данным клиентов и проверим, как масштаб признаков влияет на скорость обучения.

03Как результат зависит от шага и начальной точки

На каждом шаге обновляются оба веса3.

  1. Выберите начальные веса и шаг обучения η.
  2. Вычислите градиент ∇L при текущих весах.
  3. Обновите веса по формуле w ← w − η·∇L.
  4. Повторяйте вычисление градиента и обновление весов. В этом примере спуск останавливается, когда длина градиента становится меньше 0,001 или число итераций достигает 300.

Есть ещё одно условие остановки. Если модуль хотя бы одного веса превысит 10, программа зарегистрирует расходимость. Траектории на карте и в файле surface.py рассчитаны по одинаковым формулам.

Порог для второго веса можно вычислить точно. Каждое обновление умножает w2 на 1 − 8η. Пусть сначала w2 ≠ 0. При 0 < η < 0,125 второй вес приближается к нулю с одной стороны. При η = 0,125 он становится нулём за один шаг. При 0,125 < η < 0,25 знак меняется, но модуль веса уменьшается. При η = 0,25 модуль остаётся прежним, а при η > 0,25 растёт.

Из точки (−1,8; 1) при η = 0,15 до остановки проходит 14 итераций. Как уменьшение шага до 0,01, так и увеличение до 0,24 замедляет спуск. В первом случае нужно 276 итераций, во втором — 108. Попробуйте также один и тот же шаг 0,05 с двух начальных точек, (0; 1) и (0,3; 1). Они лежат по разные стороны от седла, поэтому спуск заканчивается в разных долинах.

04Почему спуск и lstsq находят один и тот же минимум

Для каждого клиента вычтем из прогноза фактические траты и возведём разность в квадрат. Среднее этих значений по всем клиентам называется средним квадратом ошибки (MSE). Её значение и градиент можно записать через матрицу признаков.

L(w) = (1/n)·Σ(xi·w − yi)2, ∇L(w) = (2/n)·XT(Xw − y)n — число клиентов, 1 000 · xi — строка признаков клиента i с единицей в первом столбце · yi — его траты · X — матрица всех строк, Xw − y — вектор ошибок прогноза · XT — транспонированная матрица признаков

По цепному правилу производная квадрата ошибки по одному весу равна удвоенной ошибке прогноза, умноженной на значение соответствующего признака. Умножение на XT складывает эти произведения по клиентам для каждого веса. Если приравнять градиент к нулю, получится нормальное уравнение XTXw = XTy.

Для линейной модели MSE выпукла по весам. В нашем примере столбцы матрицы X линейно независимы, поэтому минимум единственный. После стандартизации признаков спуск с η = 0,3 за 60 итераций находит веса, которые при округлении до четырёх знаков после запятой совпадают с результатом lstsq.

05Масштаб признаков и проверка градиента

Масштаб признаков влияет на скорость спуска. На исходных данных начнём с нулевых весов. Производная MSE по коэффициенту при доходе в рублях равна примерно −2,4·109, а по коэффициенту при числе заказов — −1,3·105. При шаге 3·10−10 ошибка быстро растёт. При 10−10 спуск устойчив, но даже за 10 000 итераций коэффициент при заказах достигает лишь 0,024 вместо примерно 2 550. Вычтем из значений каждого признака его среднее и разделим разности на стандартное отклонение. После такой стандартизации достаточно 60 итераций с общим шагом 0,33.

Градиент можно проверить численно. Изменим один вес на h в обе стороны, сохранив остальные веса. Разделив разность значений L на 2h, получим приближённую численную производную по этому весу. При h = 10−6 результат совпадает с формулой при округлении до восьми знаков после запятой. При h = 10−12 значения L почти равны, и ошибки округления сильнее влияют на их разность. Пример расчёта — в разделе «Код». Так же можно проверять градиенты нейросетей3.

06Ограничения градиентного спуска

В примере всего два признака и тысяча клиентов. При обучении более сложной модели приходится учитывать и другие трудности.

  • Для полного градиента нужно обработать все наблюдения на каждой итерации. Стохастический градиентный спуск (SGD) оценивает градиент по одному случайному наблюдению или по небольшой группе наблюдений3.
  • Если функция потерь вдоль одной оси меняется гораздо быстрее, чем вдоль другой, траектория может колебаться. Метод импульса учитывает предыдущие обновления, а Adam дополнительно меняет масштаб шага для каждого веса по истории градиентов7.
  • У невыпуклой функции несколько минимумов могут различаться по глубине. Кроме того, возле седловой точки градиент мал и спуск может надолго замедлиться.

Подробнее о стохастическом спуске, импульсе и Adam — в темах 08–09 блока машинного обучения.

07Производная, градиентный спуск и интеграл в Python

Примеры выполнены в Python 3.13 с NumPy 2.5.3 и pandas 3.0.5. В первом примере сравните две частные производные, вычисленные по формуле, с приближениями при разных h.

Во втором примере спуск начинается в точке x = 3 на параболе x2. Проследите за знаком и модулем x после каждого обновления. При η = 0,5 первое же обновление даёт точный минимум.

В третьем примере действуют те же условия остановки, что и на карте. Из точки (−1,8; 1) при η = 0,05 спуск занимает 52 итерации, а при η = 0,24 — 108. Из точки (1,7; 0,9) при η = 0,05 он заканчивается в правой долине.

В четвёртом примере регрессия spend ~ income + orders обучается на стандартизованных признаках. Чтобы сравнить коэффициенты с результатом lstsq на исходных данных, разделим каждый коэффициент признака на его исходное стандартное отклонение. Поправку к свободному члену вычислим по средним значениям признаков.

В пятом примере сумма площадей прямоугольников приближает интеграл плотности стандартного нормального распределения от −1 до 1. Затем код вычисляет долю клиентов в интервале доходов по гистограмме. Параметр density=True задаёт такую высоту столбцов, при которой их суммарная площадь равна единице8.
