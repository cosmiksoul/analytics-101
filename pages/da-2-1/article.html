DataFrame изнутри: индекс, типы, выборка

На примере восьми заказов вы сравните loc и iloc, найдёте заказ по индексу и выберете несколько строк по условию. Разберётесь, чем Series отличается от DataFrame, почему pandas иногда читает суммы как текст и как посчитать выручку сразу по всему столбцу.

01Как связаны столбцы таблицы

У каждого столбца DataFrame свой тип данных, а индекс у всех столбцов общий. В индексе хранятся метки строк. После сортировки метка остаётся у того же заказа, а его позиция в таблице может измениться. Чтобы найти строку по метке, используют loc, по позиции — iloc. Если нужны все заказы определённого бренда, строки можно отобрать с помощью булевой маски. Сравнение, которое вы задаёте сразу для всего столбца, служит примером векторизации.

Переключайте шаги кнопками или клавишами ← и →. Следите за заказом с меткой 2 и за строкой на позиции 2.

Как выбрать значение из Series

Series хранит последовательность значений и их метки. У неё также может быть имя1. Например, s = df["amount"] возвращает суммы заказов. Имя этой Series — amount, тип — int64, индекс взят из таблицы. Выражение s.loc[2] вернёт 910 ₽ — сумму заказа с меткой 2. Выражение s.iloc[2] вернёт третью сумму сверху, 2 640 ₽. В pandas 3 запись s[2] означает поиск по метке2. В pandas 2 при строковом индексе то же выражение могло обратиться к третьему значению по позиции.

Как выбрать столбец из DataFrame

В документации DataFrame сравнивают со словарём, где по имени столбца можно получить соответствующую Series1. Например, df["amount"] возвращает столбец сумм. Выражение df[["brand", "amount"]] возвращает таблицу из двух столбцов. Цикл for c in df перебирает имена столбцов. Если присвоить новому столбцу значения из Series, pandas сопоставит метки её индекса с метками строк таблицы. Такой способ сопоставления называют выравниванием по индексу4.

Какие типы данных используются в выгрузке

Свойство dtype показывает тип столбца. От типа зависят доступные операции и объём памяти. Так, разность двух дат даёт интервал, числовые суммы заказов можно сложить, а для работы с текстом есть методы .str. В таблице приведены замеры для 100 000 заказов из раздела «Код».

Как pandas хранит строки

В столбце типа object хранятся ссылки на объекты Python. При сравнении с названием «Сова» приходится обращаться к отдельным строковым объектам. Для сравнения чисел в столбце int64 библиотека может обрабатывать массив восьмибайтовых значений напрямую.

В pandas 2 текстовые столбцы по умолчанию получали тип object3. В pandas 3 строки по умолчанию получают тип str. Если установлен пакет pyarrow, pandas хранит текст в буферах Arrow. Без этого пакета тип по-прежнему называется str, но внутри используется массив ссылок на объекты Python2. В нашем замере с pyarrow столбец брендов занял 1,5 МБ против 7,0 МБ у object, а сравнение со строкой «Сова» выполнилось примерно в 3,5 раза быстрее. Тип object также подходит для столбцов со значениями разных типов, например pd.Series([3430, "н/д"]).

Почему числа стали строками

Допустим, в CSV встретились суммы «3430», «400», «н/д» и «1 300». При чтении с обычными настройками read_csv распознает этот столбец как текст. В pandas 3 вызов sum() соединит строки в «3430400н/д1 300». Чтобы получить сумму в рублях, сначала удалите пробелы между разрядами, затем примените pd.to_numeric(…, errors="coerce"). «н/д» станет пропуском, а «1 300» превратится в число 1300. Пустое поле в столбце, где остальные значения целые, обычно даёт другой результат при чтении CSV — числовой столбец float64 с пропуском NaN.

Как изменить индекс

По умолчанию pandas создаёт RangeIndex с метками 0, 1, 2… Пока строки идут в исходном порядке, эти метки совпадают с позициями. Сортировка или фильтрация может нарушить совпадение. Вызов set_index("order_id") вернёт таблицу, в которой метками служат номера заказов. Вызов reset_index() вернёт таблицу с новым индексом и сохранит старые метки в столбце. Именованный индекс сохранит своё имя, а безымянный обычно получит имя index. Если старые метки больше не нужны, укажите drop=True. Чтобы пронумеровать строки сразу при сортировке, используйте sort_values(…, ignore_index=True).

02Как найти второй по сумме заказ

Аналитик взял первые восемь заказов и отсортировал их от самого дорогого к самому дешёвому. Теперь второй по сумме заказ стоит 3 000 ₽. Но df.loc[1] возвращает заказ на 400 ₽. У него осталась метка 1, хотя он оказался в последней строке. Другой пример — поиск заказа с меткой 2. Выражение df.iloc[2] возвращает заказ на 2 640 ₽ с меткой 5.

Оба выражения выполняются без ошибок. Чтобы проверить результат, сначала решите, как задан нужный заказ — местом в отсортированной таблице или меткой строки.

03Как выбрать строки и столбцы

В квадратных скобках после loc указывают метки, после iloc — позиции. Чтобы отобрать строки по условию, передают булеву маску4. В примерах ниже все метки строк и имена столбцов уникальны.

Записьloc: меткиiloc: позиции
[2]строка с меткой 2 → Seriesтретья строка сверху → Series
[[2, 5]]строки с метками 2 и 5 → DataFrameстроки на позициях 2 и 5 → DataFrame
[0:2]от метки 0 до метки 2 включительнопозиции 0 и 1, конец не входит
[маска]строки, где Trueв pandas 3 допускается и булева Series; в pandas 2 для iloc нужен массив, например mask.to_numpy()
Несуществующая метка или одиночная позицияKeyErrorIndexError

В df.loc[2, "amount"] первое значение задаёт строку, второе — столбец. Результат здесь одно число. Двоеточие выбирает все строки, поэтому df.loc[:, ["brand", "amount"]] вернёт два столбца целиком. Обратите внимание на скобки. В нашей таблице df.loc[2] возвращает строку в виде Series, а df.loc[[2]] — DataFrame из одной строки.

Срез loc включает обе указанные границы5. Строки между ними идут в том порядке, в каком они расположены в таблице. Поэтому df.loc[0:2] в нашем примере вернёт семь строк, начиная с метки 0 и заканчивая меткой 2. Поскольку индекс здесь не отсортирован, при отсутствии одной из указанных граничных меток возникнет KeyError.

У самой таблицы в записи df[…] имя или список имён выбирает столбцы, булева маска выбирает строки по условию, а срез с целочисленными границами — строки по позициям6. Одиночное число pandas ищет среди имён столбцов. В нашей таблице столбца с именем 2 нет, поэтому df[2] вызовет KeyError.

Как объединить условия отбора

Сравнение столбца с одним значением даёт Series со значениями True и False и индексом исходной таблицы. Выражения df[mask] и df.loc[mask] оставляют строки, для которых условие истинно. Знак & объединяет два условия по правилу «и», | — по правилу «или». Знак ~ меняет значения маски на противоположные. Операторы and, or и not требуют одного логического значения, поэтому с такой Series возникнет ValueError4. Заключайте каждое сравнение в скобки. В записи df[df["amount"] > 1000 & (df["status"] == "paid")] операция & выполняется раньше сравнения сумм. В этой таблице результатом окажутся все восемь строк.

Сначала ответьте на вопрос, затем проверьте своё выражение в интерактиве. Здесь можно выбрать строки или столбцы, составить срез и применить маску. Результаты этих примеров проверены в pandas 3.0.5.

У строк с метками 0, 3 и 4 метки совпали с позициями. Если проверить только эти строки, легко пропустить ошибку. Для проверки попробуйте число 2. Какой заказ вернётся по метке и какой по позиции?

04Как изменить значения в исходной таблице

Чтобы заменить суммы у выбранных заказов, выполните df.loc[строки, столбцы] = значение. Оба условия выбора относятся к одной таблице. Запись df[…][…] = значение называют цепочкой присваивания (chained assignment). Сначала pandas создаёт промежуточный объект, а затем пытается записать значение в него.

В pandas 2 при выключенном режиме Copy-on-Write промежуточным объектом могла оказаться копия данных или представление, использующее память исходной таблицы3. Предупреждение SettingWithCopyWarning означало, что изменение может коснуться только промежуточного объекта. По одному предупреждению нельзя было определить, изменилась ли исходная таблица.

В pandas 3 действует правило Copy-on-Write. Можно менять результат выборки как отдельный объект. Даже если поначалу он использует ту же память, при записи pandas отделит нужные данные2. Поэтому цепочка присваивания оставляет исходную таблицу прежней. В примерах A и B pandas выдаёт предупреждение ChainedAssignmentError.

В pandas 2.3.3 строка B изменила исходную таблицу, а строка A оставила её прежней. В строке C мы явно сохранили выборку в отдельную переменную paid и изменили только её. В pandas 2.3.3 при этом появилось предупреждение, в pandas 3.0.5 — нет. Вариант D изменил сумму отменённого заказа в исходной таблице в обеих версиях.

05Как посчитать выручку без цикла по строкам

Выражение orders["amount"] * 0.9 рассчитывает сумму со скидкой для каждого заказа. В коде достаточно одной операции над столбцом. Для чисел типа int64 такую обработку выполняет скомпилированный код библиотеки8. В обычном цикле Python приходится по очереди извлекать значения и выполнять операцию для каждого из них.

В нашем примере iterrows() для каждой строки создаёт Series7. Выручку оплаченных заказов этот способ посчитал за 1,7 секунды. Циклу по двум нужным столбцам хватило 56 мс, а маске и sum() — 1,8 мс. На этих данных последний вариант оказался примерно в 900 раз быстрее iterrows().

Для отбора по условию часто подходит маска, для выбора между двумя значениями — np.where, для работы с текстом — методы .str, с датами — .dt. Если передать пользовательскую функцию в df.apply(…, axis=1), pandas по-прежнему вызовет её отдельно для каждой строки7.

06Категории, часовые пояса и общая память

Повторяющиеся значения. В нашей таблице 100 000 заказов и всего четыре разных бренда. При переводе в тип category pandas сохранит названия брендов в списке категорий, а для каждого заказа запишет короткий числовой код9. В примере столбец брендов занимает 98 КБ вместо 1,5 МБ. Сравнение с названием «Сова» выполнилось почти в 20 раз быстрее. После перевода четырёх столбцов объём таблицы уменьшился с 8,2 до 2,7 МБ. Для уникальных номеров заказов экономии может не быть. Чтобы записать значение новой категории, сначала добавьте её в список категорий.

Дата и часовой пояс. В этом примере pandas 3 распознаёт даты с точностью до микросекунд, datetime64[us]. Если строка содержит доли секунды точнее микросекунды, pandas может сохранить наносекунды2. Дата и время без часового пояса сами по себе не показывают, в каком городе или часовом поясе записано событие. tz_localize задаёт исходный пояс, tz_convert показывает тот же момент в другом поясе10. Заказ, сделанный 28 марта в 22:30 по UTC, в Минске попадёт в выручку за 29 марта.

Общая память. Представление использует память исходного объекта. В pandas 3 таблица и результат выборки могут пользоваться одними и теми же данными, пока один из объектов их не изменит. При переходе на NumPy обращайте внимание на то, чей массив вы получили. В нашем примере df["amount"].to_numpy() даёт массив, который использует память столбца и доступен только для чтения3. Если нужен независимый массив для записи, укажите copy=True.

07Что делать, если таблица не помещается в память

При обычном чтении CSV pandas помещает таблицу в оперативную память. При сортировке или преобразовании типов может понадобиться дополнительная память для промежуточных результатов11. В нашем примере 100 000 строк занимают 8,2 МБ. При таком же расходе на строку для миллиарда строк понадобилось бы около 80 ГБ ещё до начала вычислений.

  • Прочитать только нужные столбцы. Если текстовые значения часто повторяются, попробуйте тип category. В нашем примере таблица стала занимать втрое меньше памяти.
  • Обработать данные по частям. Например, можно сложить суммы заказов отдельно для каждой части файла, а в конце сложить промежуточные итоги. Такой подход разбираем в уроке 2.2.
  • Выполнить запрос к файлу. Polars поддерживает потоковую обработку для подходящих операций12. В DuckDB можно написать SQL-запрос непосредственно к файлу CSV или Parquet13.
  • Разделить работу между машинами. Распределённую обработку разбираем в теме 12 «Большие данные» блока «Дата инженерия».
