Файлы, исключения и классы

В магазине 1 200 заказов за три месяца. Одна строка в выгрузке записана в другой кодировке, и скрипт останавливается до расчёта среднего чека. Вы научитесь читать такой файл, записывать номер пропущенной строки и собирать отчёт по остальным заказам. На примере отчёта разберём, что общего у нашего класса Report и таблицы pandas.

01Почему скрипт останавливается при чтении файла

Чтобы прочитать текстовый файл, программе нужно знать его кодировку. Если при чтении в UTF-8 встретятся недопустимые для этой кодировки байты, Python выдаст исключение UnicodeDecodeError. Посмотрим, как обработать его внутри цикла и продолжить чтение. Затем опишем класс Report, чтобы хранить заказы и считать по ним выручку и средний чек.

Переключайте шаги кнопками под анимацией или стрелками ← и → на клавиатуре.

Как открыть и закрыть файл

Функция open возвращает файловый объект. Второй аргумент задаёт режим работы. В режиме "r" файл открыт для чтения. В режиме "w" Python создаёт файл или очищает существующий при открытии. Режим "a" позволяет дописать данные в конец. Буква b включает двоичный режим. При чтении такого файла мы получаем байты и сами выбираем, как их декодировать1.

Запись with open(path) as f: позволяет работать с файлом внутри блока с отступом. Здесь файловый объект служит контекстным менеджером. При выходе из блока он закроет файл, в том числе если во время чтения возникнет ошибка1.

Кодировки

Каждый байт хранит число от 0 до 255. Кодировка определяет, какая последовательность байтов соответствует символу. Например, в UTF-8 буква A из английского алфавита занимает один байт, а русская «Д» — два, D0 94. В кодировке cp1251 для «Д» достаточно одного байта C42.

Посмотрим на слово «Дом». В cp1251 первые две буквы записаны байтами C4 EE. Если прочитать их как UTF-8, байт C4 будет означать начало двухбайтовой последовательности. Байт EE для её продолжения не подходит, поэтому возникнет UnicodeDecodeError. При обратной ошибке предупреждения может и не быть. Если записать «Дом» в UTF-8 и прочитать как cp1251, получится «Р”РѕРј».

Если кодировка файла известна, укажите её при открытии, например open(path, encoding="utf-8"). Начиная с Python 3.15 режим UTF-8 включён по умолчанию. В более ранних версиях выбор кодировки по умолчанию зависит в том числе от настроек системы и режима запуска Python14.

Пути через pathlib

Путь задаёт расположение файла или папки. В Windows части пути обычно разделяют обратной косой чертой, а в macOS и Linux — прямой. В модуле pathlib части пути соединяют оператором /. У объекта Path есть методы exists() для проверки, существует ли путь, read_text() для чтения текста и read_bytes() для чтения байтов3. Примеры работы с файлами есть также в книге Эла Свейгарта4.

В выражении Path("data") / "orders.csv" задан относительный путь. Python поищет папку data в текущей рабочей папке процесса. Узнать, где начнётся поиск, можно с помощью Path.cwd().

Модули и import

Код, который нужен в нескольких программах, удобно поместить в отдельный модуль. Например, создадим файл report.py с классом Report. Строка from report import Report позволит использовать это имя в другом скрипте. При первом импорте Python выполнит код верхнего уровня модуля5. От способа импорта зависит, как обращаться к объекту. После import pathlib пишем pathlib.Path, после from pathlib import Path — просто Path. В записи import pandas as pd имя pd служит сокращением для pandas.

02Как составить отчёт, если одну строку не удаётся прочитать

Каждый понедельник аналитик получает из учётной системы CSV-файл с заказами и считает выручку и средний чек. На этой неделе скрипт завершился с ошибкой на строке 1 000. После проблемной строки в файле был ещё 201 заказ.

Строку с заказом № 999 скопировали из старой выгрузки в cp1251. Остальной файл записан в UTF-8. При попытке прочитать название категории Python выдаёт исключение UnicodeDecodeError.

Нужно сохранить номер проблемной строки и построить отчёт по заказам, которые удалось прочитать. Позже мы создадим из прочитанных данных и таблицу df — экземпляр класса DataFrame.

03Как обработать ошибку и продолжить чтение

Когда возникает исключение, Python ищет подходящий обработчик сначала в текущем вызове, затем во внешних. Если исключение осталось необработанным, скрипт завершится и Python выведет трассировку. В последней строке указаны тип исключения и сообщение. Чуть выше видно, какая строка кода вызвала ошибку.

Обработчик задают с помощью try/except. В блок try помещают операцию, при которой возможна ошибка, а в except указывают тип исключения и действия на этот случай6. В нашем примере try охватывает вызов raw.decode("utf-8") внутри цикла. Обработчик записывает номер строки, а continue переводит цикл к следующей строке файла.

Блок finally выполняется при выходе из try и при обычном завершении, и при исключении6. В него можно поместить, например, закрытие соединения с базой данных. Для файла, открытого через with, писать отдельный finally с вызовом f.close() не требуется.

Какие исключения перехватит обработчик

Типы исключений образуют иерархию классов. Класс UnicodeDecodeError наследует от UnicodeError, тот — от ValueError, а выше в этой цепочке находятся Exception и BaseException7. Обработчик except ValueError сработает и для самого ValueError, и для его подклассов, включая UnicodeDecodeError6.

Чем выше класс в иерархии, тем больше типов исключений охватывает обработчик. Большинство ошибок программы относятся к Exception. Исключения KeyboardInterrupt (например, при Ctrl+C) и SystemExit (при вызове sys.exit()) находятся в другой ветви, поэтому except Exception их пропустит7.

Ниже показана часть иерархии исключений Python и класс ReportError из этого урока. Родство встроенных классов можно проверить по их атрибуту __mro__. Прежде чем открывать дерево, попробуйте ответить на вопрос.

Свои исключения

Команда raise позволяет сообщить об ошибке, которую обнаружил сам скрипт. Например, для отчёта можно задать допустимое число пропущенных строк. Если таких строк больше, вызывающий код должен узнать, почему отчёт не сформирован.

Введём для этого собственное исключение ReportError. Определим класс class ReportError(Exception). Для прикладных исключений документация Python рекомендует базовый класс Exception7. В вызывающем коде можно написать except ReportError и обработать именно отказ при формировании отчёта.

04Что хранит экземпляр класса

Пока путь к файлу, заказы и номера пропущенных строк хранятся в трёх переменных. Опишем класс Report, чтобы у каждой выгрузки был свой отчёт с этими данными и методами для расчёта показателей8.

Отчёт за март и отчёт за апрель будут двумя экземплярами Report. Каждый хранит свой список заказов, но метод расчёта среднего чека у них общий. В Python и у самого класса могут быть атрибуты. В нашем примере путь и заказы конкретной выгрузки сохраняются в экземпляре9.

К атрибуту обращаются через точку. Например, report.orders возвращает список заказов. Выражение report.avg_check тоже обращается к атрибуту и возвращает связанный метод. Скобки в report.avg_check() вызывают его и дают средний чек по этим заказам.

При создании экземпляра Python вызывает __init__ для его инициализации. Присваивание self.orders = orders сохраняет переданный список в новом отчёте. Имя self по соглашению используют для первого параметра метода экземпляра. В нашем примере вызов report.avg_check() равносилен Report.avg_check(report). В обоих случаях параметр self получает объект report8.

Метод from_csv создаёт отчёт по файлу. Это метод класса. При вызове Report.from_csv(path) его первый параметр cls получает класс Report, а возвращаемое значение — экземпляр этого класса. В pandas похожим образом работают pd.DataFrame.from_records и pd.DataFrame.from_dict10. Над определением from_csv стоит декоратор @classmethod, который и задаёт такое поведение.

Как описать запись журнала с помощью dataclass

Для каждой ошибки сохраним номер строки, тип исключения и исходные байты. Чтобы создать класс такой записи, достаточно перечислить поля и их типы и добавить декоратор @dataclass. По умолчанию он создаст __init__, представление записи для вывода и метод сравнения записей одного класса по значениям полей11.

05Что учесть при чтении реальной выгрузки

Обработчик без типа. Запись except: иногда называют голым except. Такой обработчик перехватывает любое исключение, включая KeyboardInterrupt. Если он просто пропустит строку, за ошибку кодировки можно принять и опечатку в программе. PEP 8 рекомендует указывать конкретные типы исключений12. Здесь достаточно except UnicodeDecodeError.

Старые выгрузки в cp1251. Windows-1251 — однобайтовая кодировка, которая поддерживает русский и несколько других языков с кириллической письменностью2. Если весь файл записан в cp1251, передайте encoding="cp1251". В нашей выгрузке кодировки различаются, поэтому мы читаем файл в двоичном режиме и декодируем каждую строку отдельно. В pandas функция pd.read_csv по умолчанию выдаст UnicodeDecodeError на тех же байтах. Параметр encoding_errors="replace" позволит прочитать файл, но вместо недопустимых последовательностей появится знак «�». Списка затронутых заказов pandas при этом не составит13.

Рабочая папка при запуске скрипта. Если планировщик запустит скрипт из другой папки, по относительному пути может найтись другой файл или возникнуть FileNotFoundError. Если данные лежат рядом со скриптом в папке data, за основу пути можно взять расположение самого скрипта: Path(__file__).resolve().parent / "data" / "orders.csv". В обычной ячейке ноутбука переменная __file__ не задана. Рабочую папку ядра можно узнать вызовом Path.cwd().

07Четыре примера обработки заказов

В примерах используется файл data/orders.csv из анимации. В нём заголовок и 1 200 заказов. В строке 1 000 название категории записано в cp1251.

Откроем файл в режиме "rb" и будем декодировать строки отдельно. При чтении в текстовом режиме Python может заранее декодировать целый блок байтов. Тогда ошибка возникает ещё до того, как цикл вернёт проблемную строку. Посмотрим, что происходит при построчном декодировании без обработчика.

Теперь перехватим исключение при декодировании. Номер пропущенной строки попадёт в список bad, а в расчёт войдут 1 199 прочитанных заказов. В конце скрипт выводит значение f.closed, чтобы проверить, закрыт ли файл после выхода из with.

Метод класса Report.from_csv читает файл тем же способом. Если число пропущенных строк превышает max_bad, он выдаёт ReportError. Во втором вызове с max_bad=0 достаточно одной такой строки, чтобы отчёт не был сформирован.

Сохраним сведения об ошибке в экземпляре LogLine и запишем его поля в errors.log. Режим "w" при каждом запуске создаёт файл журнала или очищает существующий. При записи явно укажем UTF-8.
