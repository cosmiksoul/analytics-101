Файлы, исключения и классы на базовом уровне

Аналитик каждый день открывает чужие выгрузки, и одна битая строка не должна стоить всего расчёта. После этой страницы вы сможете прочитать файл в нужной кодировке, перехватить ошибку, не потеряв остальные строки, и сложить результат в собственный класс — устроенный так же, как таблица pandas.

01Идея: файл — это байты, а текст — договорённость

Файл на диске — это байты, а текстом их делает кодировка. Если одна строка сохранена в другой кодировке, Python не может её прочитать и поднимает исключение, и без перехвата весь расчёт останавливается. Конструкция try/except ловит такую ошибку: строка уходит в журнал, чтение продолжается. А класс собирает данные и действия над ними в один объект — так устроена и таблица DataFrame в pandas.

Листайте шаги кнопками или стрелками ← → на клавиатуре. Ниже — та же мысль подробно.

Страница отвечает на три вопроса: как достать данные с диска, что делать при ошибке и как сложить результат в одну вещь. Начнём с файлов.

open и with

Встроенная функция open открывает файл и возвращает файловый объект: через него читают строки по одной или записывают новые. Вторым аргументом передают режим: "r" — читать текст, "w" — записать заново, стерев старое содержимое, "a" — дописать в конец. Буква b включает двоичный режим: Python отдаёт сырые байты и ничего не расшифровывает1.

Открытый файл занимает ресурс операционной системы, и его нужно закрыть. Надёжнее всего это делает конструкция with open(path) as f:. Это контекстный менеджер: когда блок с отступом заканчивается — обычным путём или из-за ошибки, — файл закрывается сам1.

Кодировки

На диске любой файл — последовательность байтов, чисел от 0 до 255. Текстом его делает кодировка — таблица, по которой байты превращаются в буквы. В UTF-8 латиница занимает один байт, а кириллица — два: буква «Д» записана байтами D0 94. В старой кодировке Windows cp1251 та же буква — один байт C42.

Если прочитать байты cp1251 как UTF-8, Python встретит C4, будет ждать второй байт того же символа, а получит EE — букву «о». Расшифровать не выходит, и появляется ошибка UnicodeDecodeError. Обратная ошибка коварнее: UTF-8, прочитанный как cp1251, чаще всего проходит без ошибки и даёт «кракозябры» — «Дом» превращается в «Р”РѕРј».

Поэтому кодировку указывают явно: open(path, encoding="utf-8"). До Python 3.15 без этого аргумента кодировка бралась из настроек системы, и скрипт вёл себя по-разному на ноутбуке и на сервере. С 3.15 по умолчанию стоит UTF-8, но старые версии проживут ещё годы14.

Пути через pathlib

Путь — адрес файла: папки через разделитель и имя в конце. В Windows разделитель — обратная косая черта, в macOS и Linux — прямая. Модуль pathlib прячет эту разницу: путь собирают оператором /, а у объекта Path есть готовые методы — exists(), read_text(), read_bytes()3. Практические примеры с файлами и путями — у Свейгарта4.

Запись Path("data") / "orders.csv" — относительный путь: Python достраивает его от рабочей папки, из которой запустили программу. Где это ломается, — в нюансах.

Модули и import

Модуль — обычный файл .py с функциями, классами и переменными. Команда import при первом обращении выполняет этот файл и делает его содержимое доступным под именем модуля5. После import pathlib пишут pathlib.Path, после from pathlib import Path — просто Path, а import pandas as pd даёт короткое имя. Свой файл report.py с классом отчёта импортируют так же: from report import Report.

02Задача: одна строка из тысячи

Каждый понедельник аналитик забирает из учётной системы выгрузку заказов интернет-магазина — файл CSV на тысячу с лишним строк — и считает выручку и средний чек. В этот раз он остановился на строке 1 000, и отчёта нет совсем: ни по строкам до битой, ни по двумстам после неё.

Причина — одна строка, которую вставили из старой выгрузки, сохранённой в другой кодировке. Python не смог превратить её байты в текст и поднял исключение — сигнал «дальше выполнять нельзя».

Задача страницы — научиться читать и писать файлы так, чтобы плохая строка уходила в журнал, а не роняла расчёт, и понять, как устроены объекты, с которыми вы работаете в pandas. Таблица df — экземпляр класса DataFrame: в ней лежат данные и функции для работы с ними.

03Исключения: поймать ошибку и не потерять работу

Когда Python не может выполнить команду, он создаёт объект-исключение и бросает его. Исключение летит вверх по программе, пока кто-нибудь его не перехватит. Если перехватчика нет, программа останавливается и печатает трассировку ошибки. Читают её снизу вверх: последняя строка — тип ошибки и сообщение, выше — строка кода, где всё случилось.

Перехватчик — конструкция try/except. В try пишут код, который может упасть, в except ТипОшибки — что делать, если упал6. В анимации except окружает одну операцию — расшифровку строки, поэтому ошибка не прерывает цикл: номер строки уходит в журнал, а continue переходит к следующей.

У try есть ещё блок finally. Он выполняется всегда: была ошибка или нет, перехватили её или она летит дальше6. В нём закрывают то, что открыли: соединение с базой, временный файл. Для файлов эту работу берёт на себя with — по сути это try/finally с f.close() внутри.

Типы ошибок выстроены в дерево

Каждый тип ошибки — класс, и классы выстроены в иерархию. UnicodeDecodeError — частный случай UnicodeError, тот — частный случай ValueError, дальше идут Exception и на самом верху BaseException7. Правило перехвата одно: except X ловит X и всё, что ниже X в дереве6.

Чем выше класс в except, тем больше ошибок он ловит, включая те, о которых вы не думали. А except Exception ловит почти всё, но не KeyboardInterrupt и SystemExit: остановка по Ctrl+C и выход через sys.exit() нарочно вынесены в отдельные ветки, чтобы программу можно было прервать7.

Ниже — настоящее дерево исключений Python 3.13: оно собрано по __mro__, цепочке родителей каждого класса, и дополнено одним своим исключением из раздела «Код». Сначала предскажите ответ.

Свои исключения

Исключение можно бросить и самому — командой raise. Так код честно говорит «дальше считать нельзя». Если битых строк в выгрузке больше пяти, отчёт лучше не собирать вовсе, чем показать выручку по половине файла.

Для такого случая заводят своё исключение — класс с родителем Exception: class ReportError(Exception). Документация советует наследовать именно от Exception, а не от BaseException7. Своё имя делает ошибку понятной в трассировке, а код выше может перехватить ровно её: except ReportError.

04Классы: чертёж и экземпляры

В скрипте из анимации результат разбросан по переменным: path, orders, bad. Когда файлов станет пять, переменных станет двадцать. Класс собирает данные и действия над ними в одно целое8.

Класс — чертёж. Он описывает, какие поля будут у объекта и что объект умеет, но сам данных не хранит. По чертежу создают экземпляры, и у каждого свои значения: отчёт за март и отчёт за апрель — два экземпляра одного класса Report9.

Атрибут — значение, привязанное к объекту: report.path, report.orders. Метод — функция внутри класса, которая работает с данными своего объекта: report.avg_check(). Метод вызывают со скобками, атрибут — без.

__init__ — метод, который Python вызывает при создании экземпляра. В нём входные данные раскладывают по атрибутам: self.orders = orders. self — первый параметр любого метода, тот экземпляр, с которым метод сейчас работает. Вызов report.avg_check() Python превращает в Report.avg_check(report), поэтому внутри метода self — это report8. Имя self — договорённость, а не ключевое слово.

from_csv — метод класса: его вызывают у самого класса, Report.from_csv(path), и он возвращает готовый экземпляр. Такие запасные конструкторы есть и в pandas: pd.DataFrame.from_records и pd.DataFrame.from_dict10. Метод класса помечают строкой @classmethod над определением. Это декоратор — приставка, которая меняет поведение функции или класса под ней.

dataclass для записи

Иногда объект нужен только как запись из нескольких полей: строка журнала ошибок с номером строки файла, типом ошибки и сырыми байтами. Писать для неё __init__ вручную скучно. Декоратор @dataclass делает это сам: вы перечисляете поля с типами, а он добавляет __init__, читаемый вид для print и сравнение двух записей по значениям11.

05Нюансы: голый except, cp1251 и пути

Голый except скрывает ошибки. Голый except — except: без типа — ловит вообще всё: битую кодировку, опечатку в имени переменной, деление на ноль и даже Ctrl+C. Скрипт с таким перехватчиком «работает», но молча выбрасывает строки по причинам, о которых вы не узнаете. PEP 8 советует называть конкретные типы и предупреждает, что голый except мешает прервать программу по Ctrl+C12. Если нужно поймать «всё прочее», пишут except Exception as e и обязательно записывают e в журнал.

cp1251 в старых выгрузках. Windows-1251 — однобайтовая кодировка для кириллицы: в документации Python она отмечена для болгарского, белорусского, македонского, русского и сербского2. Если в cp1251 весь файл, достаточно encoding="cp1251". Если кодировки перемешаны, как в учебной выгрузке, читают байты и расшифровывают построчно. pandas ведёт себя так же, как наш первый скрипт: pd.read_csv на учебном файле падает с той же UnicodeDecodeError, а параметр encoding_errors="replace" заменяет нерасшифрованные байты знаком «�» — тихо, без журнала13.

Относительные пути ломаются при запуске из другой папки. Path("data/orders.csv") ищется от рабочей папки. Скрипт работает, пока его запускают из папки проекта, и падает с FileNotFoundError и сообщением «No such file or directory: 'data/orders.csv'», когда его зовёт планировщик или коллега из соседней папки. Надёжнее строить путь от файла самого скрипта: Path(__file__).parent / "data" / "orders.csv". В ноутбуке __file__ нет, там рабочая папка — та, где лежит ноутбук.
