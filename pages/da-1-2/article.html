Типы и коллекции

У каждого значения в Python есть тип, а значения складывают в коллекции: список, кортеж, словарь и множество. После страницы вы сможете выбрать коллекцию под задачу, разобрать JSON-ответ сервиса и не попасться на то, что две переменные смотрят на один и тот же список.

01Идея: у каждого значения есть тип

Каждое значение в Python — объект своего типа: число, строка, True или None. Когда значений много, их складывают в коллекции, и четыре главные по-разному обходятся с одними и теми же данными. Список хранит всё по порядку вместе с повторами, кортеж — то же, но его нельзя изменить, множество оставляет только уникальные значения, а словарь находит значение по ключу.

Листайте шаги кнопками или стрелками ← → на клавиатуре. Ниже — та же мысль подробно.

Всё, с чем работает Python, — объекты: число, строка, список, даже None. У каждого объекта есть тип, значение и своё место в памяти1. Тип определяет, что с объектом можно делать: числа складывают, строки режут на части, в список дописывают элементы. Узнать тип можно функцией type(): type(1200) вернёт int.

Числа: int и float

int — целое число любой длины: 2 ** 100 Python посчитает точно, до последней цифры2. float — дробное число, которое хранится в двоичном виде с конечной точностью. Обычное деление всегда даёт float: 10 / 2 равно 5.0.

Отсюда самая известная странность: 0.1 + 0.2 в Python равно 0.30000000000000004, и сравнение 0.1 + 0.2 == 0.3 даёт False. Дробь 0,1 в двоичной системе бесконечная, как 1/3 в десятичной, поэтому хранится её ближайшее приближение. При сложении погрешности двух приближений складываются и становятся видны3. Это свойство формата чисел, а не ошибка Python: JavaScript покажет то же самое.

Строки и их методы

Строка (str) — последовательность символов в кавычках: 'Сова', "2026-03-14". У строки много методов, их вызывают через точку после значения. ' Сова '.strip() убирает пробелы по краям, .lower() переводит в нижний регистр, .split(',') режет строку на список кусков, .replace('-', '.') заменяет символы.

Строку нельзя изменить на месте. Каждый метод возвращает новую строку, а исходная остаётся прежней: после s.upper() в s всё ещё 'Сова'4. Чтобы сохранить результат, его присваивают: s = s.upper().

bool и None

bool — тип с двумя значениями, True и False. Их возвращают сравнения и проверки: amount > 1000, 'Луч' in brands. bool — разновидность int, и True считается единицей2, поэтому sum([True, False, True]) даёт 2. Так считают, сколько заказов прошло условие.

None — отдельное значение «ничего нет»: промокод не указан, поле не заполнено. Это не ноль и не пустая строка: None == 0 даёт False. Проверяют его выражением x is None.

02Задача: какая коробка под какие данные

На странице 1.1 заказы лежали в одном списке сумм. В жизни у заказа есть номер, дата, бренд, сумма и признак оплаты, а сервис магазина отдаёт заказы пачкой, в виде вложенных словарей и списков. Прежде чем считать, данные раскладывают так, чтобы нужный вопрос решался одной строкой.

Вопросы к данным бывают трёх видов: найти по ключу, перебрать по порядку, проверить принадлежность. Под каждый в Python есть своя структура.

03Четыре коллекции: порядок, повторы, изменяемость

Коллекция — объект, внутри которого лежат другие объекты. Встроенных коллекций в Python четыре, и каждая отвечает на свой вопрос5.

  • Список (list) [1200, 850, 2300] хранит элементы по порядку, вместе с повторами. Его можно дописывать, сокращать и править.
  • Кортеж (tuple) (2026, 3) тоже хранит порядок и повторы, но после создания не меняется.
  • Словарь (dict) {'Сова': 3, 'Кедр': 1} хранит пары «ключ → значение». Ключи уникальны, значение находят по ключу. С Python 3.7 словарь гарантированно помнит порядок, в котором добавляли ключи2.
  • Множество (set) {'Сова', 'Кедр'} хранит только уникальные элементы и не хранит порядок. Пустое множество пишут set(), потому что пустые фигурные скобки {} — это словарь.

Главное различие между списком и кортежем — изменяемость. Изменяемый объект (mutable) меняется на месте: список после append — тот же объект, только длиннее. Неизменяемый (immutable) поменять нельзя, можно только собрать новый. Неизменяемы числа, строки и кортежи6. Поэтому кортеж берут для того, что не должно меняться: пара «год, месяц», координаты, запись из выгрузки. Подробно списки, словари и кортежи разобраны в главах 9–11 «Think Python»7.

Скорость поиска

Проверка 'Луч' in brands в списке идёт перебором: Python сравнивает элементы по очереди, пока не найдёт нужный. В списке из миллиона элементов это до миллиона сравнений.

Множество и словарь устроены иначе. Для каждого элемента они вычисляют хэш — число, которое получается из самого значения, — и кладут элемент в ячейку по этому числу. Чтобы проверить принадлежность, достаточно посчитать хэш и заглянуть в одну ячейку. По документации Python, время x in s для списка растёт вместе с его длиной, а для множества в среднем от размера не зависит8.

В песочнице учебника поиск числа в конце списка из миллиона элементов занял около 5 мс, во множестве — меньше десятой доли микросекунды. Убрать повторы из 20 000 чисел циклом с проверкой if x not in seen вышло примерно за полсекунды, а set(data) — меньше чем за миллисекунду. На вашей машине числа будут другими, но разрыв останется.

04Индексы, срезы и вложенные структуры

В списке, кортеже и строке элементы пронумерованы. Номер элемента — индекс — начинается с нуля. В списке a = [1200, 850, 2300, 640, 1750] элемент a[0] — это 1200, а a[4] — 1750. Отрицательный индекс считает с конца: a[-1] — последний элемент.

Срез вырезает кусок последовательности и возвращает его как новый объект того же типа4.

a[start : stop : step]start — с какого индекса брать, включительно (если пропущен — с начала); stop — на каком остановиться, сам он не входит (если пропущен — до конца); step — шаг (по умолчанию 1, отрицательный идёт с конца).

Любую часть среза можно опустить. a[1:3] — это [850, 2300], a[:2] — первые два элемента, a[-2:] — последние два, a[::2] — каждый второй. Отрицательный шаг идёт с конца, поэтому a[::-1] возвращает новый список задом наперёд: [1750, 640, 2300, 850, 1200].

Срезы работают и на строках. Если дата всегда записана как '2026-03-14T10:22:05', с ведущими нулями, позиции символов фиксированы: [:4] даёт год, [5:7] — месяц, [:7] — год с месяцем. Так заказы группируют по месяцам без разбора даты, это есть в коде ниже.

Коллекции можно класть друг в друга: список словарей, словарь списков. Так устроен JSON — текстовый формат, в котором сервисы обмениваются данными. Когда аналитик запрашивает заказы у API магазина, ответ приходит строкой JSON. 05Ссылка или копия

Переменная в Python — не коробка с данными, а имя, которое указывает на объект. Такую связь называют ссылкой. Присваивание b = a не копирует список, а даёт тому же объекту второе имя1. С числами и строками этого не видно, их нельзя изменить. Со списком разница становится заметной. Сначала предскажите, потом проверьте.

Python Tutor рисует память так же: имена слева, объекты справа, стрелки между ними10. Туда можно вставить свой код и пройти его по шагам.

b = a.copy() создаёт копию — новый список с теми же элементами, и у каждого имени появляется свой объект. То же дают a[:] и list(a). Проверить, один ли это объект, можно оператором is: a is b сравнивает сами объекты, а a == b — только содержимое.

Кортежу копия не нужна: его нельзя изменить ни через одно имя. Запись a += (990,) не трогает старый кортеж, а собирает новый и переставляет на него имя a. У списка та же запись a += [990] работает как append и меняет общий объект, а новый список создаёт только a = a + [990].

Где это бьёт по аналитику: список заказов передали в функцию очистки, она удалила из него тестовые заказы, и исходный список тоже стал короче. Если исходные данные ещё понадобятся, в функцию отдают копию.

06Нюансы: ключи, вложенные копии и сравнение float

Ключ словаря должен быть хэшируемым. Словарь ищет ключ по хэшу, поэтому хэш ключа не должен меняться, пока ключ лежит в словаре. Числа, строки и кортежи из них годятся, список — нет: {[2026, 3]: 4990} падает с ошибкой TypeError: unhashable type: 'list'. Отчёт с ключом «год, месяц» пишут через кортеж: {(2026, 3): 4990}11. Кортеж со списком внутри тоже не хэшируется.

Срез копирует список, но не то, что лежит внутри. a[:] и a.copy() делают поверхностную копию: новый внешний список со ссылками на те же вложенные объекты. Если rows = [[1200, 'Сова'], [850, 'Кедр']] и c = rows[:], то c.append(…) исходник не тронет, а c[0][0] = 0 поменяет и rows[0][0]. Независимую копию всей структуры делает copy.deepcopy12.

float сравнивают с допуском. Вместо x == 0.3 пишут math.isclose(x, 0.3). По умолчанию функция считает числа равными, если они совпадают примерно в девяти значащих цифрах13. Деньги надёжнее хранить в копейках как int или считать модулем decimal3.

07Ограничения: списки медленны для расчётов

Список хранит не сами числа, а ссылки на отдельные объекты-числа14. Цикл по такому списку Python выполняет шаг за шагом и на каждом шаге заново выясняет, что за объект перед ним. На тысяче заказов это незаметно, на миллионе — уже да.

Для расчётов на числах есть NumPy. В его массиве все числа одного типа и одного размера, а операция над всем массивом выполняется заранее скомпилированным кодом на C, без цикла Python15. В песочнице учебника умножить миллион сумм на 0,9 циклом по списку заняло около 40 мс, тем же выражением в NumPy — около 1 мс.

08Код: от JSON к частотам и месяцам

Три блока идут подряд в одном ноутбуке: второй и третий берут orders из первого. Данные — пять учебных заказов из анимации, с теми же суммами, что на странице 1.1. Первый блок разбирает ответ API: превращает строку JSON в словари и списки и показывает, какими типами Python стали поля заказа.

Второй блок считает частоты брендов. Сначала вручную: словарь и метод .get(b, 0), который возвращает 0 для ключа, которого ещё нет. Потом одной строкой через Counter из модуля collections16. Множество в конце даёт уникальные бренды. Его печатают через sorted: порядок элементов множества не гарантирован, а у строк он меняется от запуска к запуску.

Третий блок режет строку с датой срезами и методом split, а потом собирает выручку по месяцам в словарь с ключом «год-месяц».
