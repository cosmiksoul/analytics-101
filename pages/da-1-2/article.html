Типы и коллекции

В учебном магазине пять заказов от трёх брендов. Чтобы сохранить названия в порядке заказов, найти заказ по номеру или выбрать бренды без повторов, понадобятся разные коллекции. Разберём, как тип значения определяет доступные операции, прочитаем ответ магазина в формате JSON и проверим, что происходит со списком, когда ему дают второе имя.

01Какие операции доступны для разных типов

Число 1200, строка «Сова» и список заказов — примеры объектов Python. Если записать бренды заказов в список, название одного бренда может встретиться несколько раз. Если собрать те же названия во множество, каждое встретится только один раз. В анимации сравним оба варианта со словарём и кортежем.

Переключайте шаги кнопками под анимацией или стрелками ← и → на клавиатуре.

У каждого объекта есть тип, значение и идентичность. Даже списки с одинаковым содержимым могут быть разными объектами1. Тип определяет, какие операции доступны. Например, числа можно умножать, из строки выбирать символы, а в список добавлять элементы. Функция type возвращает тип объекта. Для type(1200) результатом будет int.

Целые числа и числа с плавающей точкой

Тип int служит для целых чисел. Их размер ограничен доступной памятью. Например, Python вычислит 2 ** 100 точно2. Числа типа float хранятся с конечной точностью в двоичной системе. При делении двух целых чисел оператором / результат тоже имеет тип float, даже если частное целое. Например, 10 / 2 даёт 5.0.

Числа 0,1 и 0,2 нельзя точно записать конечной двоичной дробью, поэтому Python хранит ближайшие приближения. Их сумма тоже округляется. В результате 0.1 + 0.2 даёт 0.30000000000000004, а сравнение 0.1 + 0.2 == 0.3 возвращает False3.

Строки и их методы

Строка (str) — последовательность символов. В коде её можно записать в кавычках, например 'Сова' или "2026-03-14". У строк есть методы, которые вызывают через точку. Выражение ' Сова '.strip() удаляет пробелы по краям. Метод lower() переводит буквы в нижний регистр, split(',') делит строку по запятым и возвращает список, а replace('-', '.') заменяет дефисы точками.

Строки неизменяемы4. Если s = 'Сова', вызов s.upper() вернёт 'СОВА', а в s останется 'Сова'. Чтобы пользоваться результатом под тем же именем, запишите s = s.upper().

bool и None

У логического типа bool два значения — True и False. Одно из них получится, например, при сравнении amount > 1000 или при проверке 'Луч' in brands. Тип bool — подкласс int2. При сложении True учитывается как единица, а False как ноль. Так можно посчитать заказы, которые удовлетворяют условию. Например, sum([True, False, True]) вернёт 2.

Значением None часто обозначают отсутствие данных. Например, у заказа без промокода поле promo может содержать None. Ноль и пустая строка — другие значения. Чтобы проверить, отсутствует ли промокод, запишите promo is None.

02Как выбрать коллекцию для данных о заказах

В уроке 1.1 мы работали со списком сумм. Теперь у каждого заказа есть номер, дата, бренд, сумма и признак оплаты. Сервис магазина присылает сразу несколько таких записей.

В одном отчёте нужно найти сумму заказа по его номеру, в другом — вывести суммы в порядке поступления, в третьем — проверить, входит ли бренд в число партнёров. Выбор коллекции зависит от того, какую операцию предстоит выполнять.

03Чем различаются список, кортеж, словарь и множество

В Python есть несколько встроенных типов коллекций. Для работы с заказами сравним четыре из них5.

  • Список (list) хранит элементы по порядку и допускает повторы. В список [1200, 850, 2300] можно добавить новую сумму, заменить существующую или удалить её.
  • Кортеж (tuple) тоже сохраняет порядок и допускает повторы. Состав кортежа задают при создании. Например, (2026, 3) хранит номер года и месяца.
  • Словарь (dict) хранит пары «ключ — значение». В примере {'Сова': 3, 'Кедр': 1} по ключу 'Сова' можно узнать число заказов этого бренда. Ключи уникальны. Одно и то же значение может встречаться у разных ключей. Начиная с Python 3.7 словари гарантированно сохраняют порядок добавления ключей2.
  • Множество (set) удобно для проверки принадлежности и хранения уникальных элементов. Например, {'Сова', 'Кедр'} содержит два бренда. Порядок обхода множества не гарантирован. Для пустого множества используют set(), поскольку запись {} создаёт пустой словарь.

Одно из свойств коллекции — изменяемость. После вызова append список остаётся тем же объектом, но в нём появляется новый элемент. Числа, строки и кортежи относятся к неизменяемым типам6. В кортеже удобно хранить пару «год, месяц» или координаты точки. Подробнее списки, словари и кортежи разбираются в главах 9–11 книги Think Python7.

Скорость поиска

Чтобы проверить, есть ли 'Луч' в списке brands, Python сравнивает элементы по очереди и останавливается на первом совпадении. Если значения в списке нет или оно стоит в самом конце, придётся проверить весь список.

В множестве поиск начинается с хэша элемента, а в словаре — с хэша ключа. Хэш помогает определить, где искать в таблице. Иногда приходится проверить несколько ячеек. В среднем число проверок остаётся примерно постоянным, даже когда коллекция растёт8.

В замерах для урока поиск числа в конце списка из миллиона элементов занял около 5 мс, а поиск того же числа в готовом множестве — меньше 0,1 мкс. С удалением повторов из 20 000 чисел получилась похожая разница. Цикл с проверкой if x not in seen по списку занял около половины секунды, вызов set(data) — меньше миллисекунды. Файл speed.py из материалов урока позволяет повторить эти замеры на своём компьютере.

04Индексы, срезы и вложенные структуры

У каждого элемента списка, кортежа или строки есть индекс — номер позиции, начиная с нуля. Например, в списке a = [1200, 850, 2300, 640, 1750] выражение a[0] даёт 1200, а a[4] — 1750. Отрицательные индексы отсчитывают позиции от конца. Индекс -1 указывает на последний элемент непустой последовательности.

Срез выбирает элементы последовательности по диапазону индексов и шагу. Срез списка возвращает новый список, срез строки — строку, срез кортежа — кортеж4.

a[start : stop : step]start задаёт начальный индекс, stop — границу, которая не входит в срез. По умолчанию шаг равен 1. При положительном шаге индексы увеличиваются, при отрицательном — уменьшаются. Если опустить обе границы, Python пройдёт последовательность от начала к концу или от конца к началу в зависимости от знака шага.

Например, a[1:3] вернёт [850, 2300], а a[:2] — первые два элемента. Срез a[-2:] выбирает последние два элемента, a[::2] — каждый второй, начиная с первого. Если взять шаг -1 и опустить обе границы, получится список в обратном порядке. В этом примере a[::-1] равно [1750, 640, 2300, 850, 1200].

Из строки '2026-03-14T10:22:05' срез [:4] извлечёт год, [5:7] — месяц, а [:7] — год и месяц вместе. Это удобно для группировки заказов, когда даты в данных всегда записаны в одном формате с ведущими нулями.

Коллекции можно вкладывать друг в друга. Например, список может содержать словари с заказами. Функция json.loads преобразует текст ответа в объекты Python9.

05Ссылка или копия

Переменная в Python — имя, связанное с объектом. Присваивание b = a создаёт ещё одну ссылку на тот же объект1. Что покажет print(b), если затем добавить число в список через a? Выберите ответ и проверьте его в интерактиве.

В Python Tutor можно запустить свой фрагмент кода по шагам и увидеть, на какие объекты ссылаются имена после каждой команды10.

Команда b = a.copy() создаёт копию списка. Сразу после этой операции списки содержат одни и те же элементы. Для них a == b вернёт True, а a is b — False, поскольку это два разных объекта. Копию списка также можно получить с помощью a[:] или list(a).

Если a и b ссылаются на один кортеж чисел, после a += (990,) имя a будет ссылаться на новый кортеж, а b — на исходный. Для списка a += [990] добавляет элемент в существующий объект, поэтому результат виден и через b. Выражение a = a + [990] создаёт новый список.

Представьте, что функция очистки удаляет тестовые заказы из переданного ей списка. Если для сверки понадобится полный список, передайте функции его копию. Если же функция правит поля заказов, нужно учитывать, что сами записи могут оставаться общими.

06Ключи словаря, вложенные копии и сравнение чисел

Какие значения подходят для ключей словаря. Для поиска словарь использует хэш ключа. В течение жизни объекта его хэш должен оставаться постоянным, а у равных ключей хэши должны совпадать11. Числа и строки подходят. Кортеж подходит, если все его элементы хэшируемы. В отчёте за март можно записать {(2026, 3): 4990}. Если вместо кортежа поставить список, Python выдаст TypeError: unhashable type: 'list'. Кортеж со списком внутри вызовет ту же ошибку.

Что остаётся общим при копировании списка. Выражения a.copy() и a[:] создают поверхностную копию. Новый внешний список ссылается на те же вложенные объекты. Например, возьмём rows = [[1200, 'Сова'], [850, 'Кедр']] и c = rows[:]. После c.append([640, 'Луч']) в rows останутся две записи. Но после c[0][0] = 0 сумма первого заказа в rows тоже станет нулевой. Чтобы независимо редактировать вложенные записи в этом примере, используйте copy.deepcopy(rows)12.

Как сравнить приближённые значения. Пусть x = 0.1 + 0.2. Выражение math.isclose(x, 0.3) вернёт True. По умолчанию функция допускает разницу до одной миллиардной от большего из двух модулей13. Для денежных расчётов с точностью до копейки можно хранить суммы в целых копейках или использовать десятичные числа из модуля decimal3.

07Когда для вычислений нужен массив

В CPython список хранит ссылки на объекты14. Если умножить каждую сумму заказа на 0,9 в обычном цикле, интерпретатор выполнит отдельную операцию для каждого элемента. На большом списке время таких операций складывается.

В NumPy можно записать числа в массив одного числового типа и умножить весь массив на коэффициент одной командой. Перебор элементов выполнит скомпилированный код библиотеки15. В замере для урока умножение миллиона сумм на 0,9 заняло около 40 мс в цикле по списку и около 1 мс при работе с готовым массивом NumPy.

08Как посчитать заказы по брендам и месяцам

Выполняйте три блока по порядку в одном ноутбуке. Первый разбирает JSON с пятью заказами из анимации и создаёт список orders. Он понадобится в двух следующих блоках. Посмотрите на типы полей первой записи и на то, как признак оплаты влияет на итоговую сумму.

Второй блок считает, сколько заказов относится к каждому бренду. Если бренд встречается впервые, counts.get(b, 0) вернёт ноль. В конце сравним результат с подсчётом через Counter из модуля collections16. Уникальные названия получим с помощью множества. Перед выводом отсортируем их с помощью sorted, чтобы видеть бренды в одном и том же порядке при каждом запуске.

В третьем блоке из строки с датой извлекаем год и месяц, затем складываем суммы всех заказов за каждый месяц. Мартовский итог включает и неоплаченный заказ. Сумму оплаченных заказов мы отдельно посчитали в первом блоке.
