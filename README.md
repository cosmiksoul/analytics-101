# Аналитика 101

Бесплатный интерактивный курс о работе с данными. Готов модуль «Дата аналитика»: 11 тем, 43 страницы. Модули BI, «Дата инженерия», ML и AI-инженерия в работе, в оглавлении у них пока только список тем.

Сайт статический: страницы, главная и оглавление собираются из этой папки скриптами на Python без сторонних библиотек, материалы для скачивания лежат в `dist/materials/` готовыми. Как выложить сайт на GitHub Pages — в `DEPLOY.md`.

## Что где

| папка / файл | что это |
|---|---|
| `build.py` | сборка страниц: `pages/<id>/` → `dist/standalone/<файл>.html` (и `dist/artifact/` — версия для артефакта claude.ai) |
| `engine/` | движок страниц: `shell.html` (шапка, боковина), `engine.js` (сцена, вопросы, подсказки к терминам, сноски, меню «Обсудить с ИИ», материалы), `base.css`, `extra.css`; для главной и оглавления — `site.css`, `site.js` |
| `engine/course.json` | структура курса: модули, темы, страницы, описания тем, лид главной. Генерирует `tools/make_course.py` |
| `engine/notebooks.json` | ссылки на блокноты NotebookLM по темам; пока ссылки пустые, кнопка в меню серая с пометкой «скоро» |
| `pages/<id>/` | одна страница: `meta.json`, `article.html` (текст), `page.js` (сцена, интерактивы, код, вопросы, глоссарий, список материалов), `page.css`; `materials/` и `data/` — исходники материалов страницы |
| `data/<набор>/` | общие наборы данных тем 03–11: генераторы, файлы, README для читателя |
| `dist/materials/` | собранные материалы: папка и архив на страницу, общие наборы `data/<набор>/` и `data-<набор>.zip`, `index.json` — карта для сборки страниц |
| `tools/` | `build_site.py` (сайт в `site/`), `check_site.py` (ссылки и материалы), `make_course.py`, `build_materials.py` и `matlib.py` (материалы страниц), `build_shared_data.py` (общие наборы), `export_md.js` (страница в Markdown), `qa.js` и `shot.js` (проверки в браузере), `lint_ru.py` |
| `ENGINE.md` | правила для тех, кто делает страницы: порядок разделов, разметка, уроки пачек, список материалов |
| `DEPLOY.md` | сборка и публикация на GitHub Pages |

## Сборка

```bash
python3 build.py --all            # 43 страницы → dist/standalone/
python3 tools/build_site.py       # site/: главная, оглавление, 404, страницы, materials/
python3 tools/check_site.py       # внутренние ссылки, якоря, файлы материалов
python3 -m http.server -d site 8000   # просмотр: http://localhost:8000/
```

Нужен Python 3.13. Для проверок в браузере (`tools/qa.js`, `tools/shot.js`, `tools/export_md.js`) — Node.js и Playwright. Материалы пересобираются отдельно и долго: нужны PostgreSQL 16, Jupyter и библиотеки тех версий, на которых запускался код страниц (Python 3.13, pandas 3.0, NumPy 2.5, DuckDB 2.0); подробности — в `tools/build_materials.py` и `ENGINE.md`.

Ссылки на материалы в страницах относительные (`materials/…`): они работают на сайте и в собранной папке `site/`, а у страниц, открытых прямо из `dist/standalone/`, не находятся.
