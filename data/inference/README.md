# Учебные данные для темы 06 «Статистический вывод»

Тот же интернет-магазин, что в темах 02–05. Файлы и генераторы не меняйте: на них стоят числа пяти страниц. На страницах называем данные учебными.

| файл | генератор | зерно | страница |
|---|---|---|---|
| `users.csv` — 100 000 пользователей за квартал | `gen_users.py` | 601 | 6.1 |
| `pilot.csv` — 40 + 40 чеков пилота кнопки | `gen_pilot.py` (`--search` — перебор зёрен 600–999) | 769 | 6.3 |
| `ab.csv` — A/B-тест, 40 000 пользователей; `paired.csv` — 30 клиентов «до и после» | `gen_ab.py` (`--scene <путь>` пишет scene.json страницы 6.4) | 604 | 6.4 |
| `discounts.csv` — 120 заказов со скидкой | `gen_discounts.py` | 6505 | 6.5 |

Код страниц и генераторы запускаются из корня учебника: `python3 data/inference/gen_users.py`. `gen_ab.py` читает `data/probability/`.
Скрипты страниц, которые берут отсюда данные или функции: `pages/da-6-1/data/gen_page.py`, `pages/da-6-3/data/gen_scene.py` и `verify_js.py` (импортируют `gen_pilot`), `pages/da-6-5/data/gen.py` (импортирует `gen_discounts`), `pages/da-6-4/data/inject.py`.
В материалы читателя набор кладёт `tools/build_shared_data.py inference` (README — `README.reader.md`).
Точные числа считайте из файлов, а не из этой таблицы. Окружение: Python 3.13.18, NumPy 2.5.3, pandas 3.0.5, SciPy 1.18.1.
