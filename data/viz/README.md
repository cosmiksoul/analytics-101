# Учебные данные для темы 08 «Визуализация в Python»

Тот же интернет-магазин, что в темах 02–07. Сгенерировано `gen.py`, seed 808; файл и генератор не меняйте. На страницах называем данные учебными.

`sales_monthly.csv` — 960 строк, **длинный формат** (удобно для seaborn, `FacetGrid` и plotly.express): `month` (`2024-01` … `2025-12`), `channel` (10 каналов продаж: сайт, приложение, маркетплейс, поиск, рассылка, соцсети, партнёры, кешбэк-сервисы, колл-центр, офлайн-точки), `country` (BY, RU, KZ, UZ), `revenue` (₽).

Что заложено:
- **Сюжет для 8.4:** в июне 2025 вышел релиз мобильного приложения — выручка канала «приложение» удвоилась (май 2025 ≈ 3,0 млн ₽, июль ≈ 5,9 млн, июнь — месяц разгона ≈ 4,5 млн). Десять линий каналов — готовый «график-спагетти» для переделки.
- Сезонность: пик в декабре, провал летом (±12%).
- «Колл-центр» медленно угасает; остальные каналы слегка растут.
- Доли каналов в 2025: сайт ≈ 27%, маркетплейс ≈ 19%, приложение ≈ 15%, поиск ≈ 13%, дальше мелочь от 7% до 2% — хороший материал против круговой диаграммы.
- Четыре страны — для малых множителей.

Для дат на оси и дневных рядов можно брать `data/eda/daily_metrics.csv` (тема 07) и `data/probability/daily_orders.csv` (тема 05).

Окружение: Python 3.13.18, pandas 3.0.5, NumPy 2.5.3, Matplotlib 3.10.0, seaborn 0.13.2, plotly 7.1.0, kaleido 1.5.0 (экспорт plotly в PNG/SVG работает).
