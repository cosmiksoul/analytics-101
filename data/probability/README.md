# Учебные данные для темы 05 «Вероятность»

Тот же интернет-магазин, что в темах 02–04. Сгенерировано `gen.py`, seed 505; файлы и генератор не меняйте. На страницах называем данные учебными.

| файл | строк | что внутри |
|---|---|---|
| `visits.csv` | 100 000 | `visit_id`, `source` (органика 55% / реклама 30% / рассылка 15%), `bought` 0/1. Доля покупок: органика 2,5%, реклама 4%, рассылка 6% — источник и покупка **зависимы**. P(купил) ≈ 0,034, P(купил \| реклама) ≈ 0,039, P(реклама \| купил) ≈ 0,35 |
| `checks.csv` | 20 000 | `order_id`, `amount` ₽ — оплаченные чеки. Смесь: 97% розница (логнормальное, медиана ≈ 3 000 ₽, σ = 0,6) и 3% опт (логнормальное, медиана ≈ 25 000 ₽). Среднее ≈ 4 330, медиана ≈ 3 080, максимум ≈ 109 000. Одно логнормальное подходит плохо в хвосте — это и есть нюанс про смеси |
| `order_gaps.csv` | 5 000 | `gap_days` — дни между заказами клиента, экспоненциальное со средним 12 |
| `daily_orders.csv` | 90 | `date`, `orders` — заказы за день, январь–март 2026, Пуассон с λ = 38 |

Точные числа считайте из файлов, а не из этой таблицы. Окружение: Python 3.13.18, NumPy 2.5.3, pandas 3.0.5, SciPy 1.18.1.
