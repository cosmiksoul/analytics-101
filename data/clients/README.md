# Учебные клиенты для темы 04 «Математика для данных»

`clients.csv` — 1 000 учебных клиентов того же интернет-магазина, что в теме 03 (база `data/shop`). Сгенерированы `gen.py`, seed 404; не меняйте файл и генератор. На страницах называем данные учебными.

| столбец | что это |
|---|---|
| `client_id` | 1…1000 |
| `age` | возраст, 18–70 лет |
| `income` | доход в месяц, ₽ (25 000–314 000, среднее ≈79 000) — в тысячи раз крупнее возраста: удобно показывать, зачем масштабировать признаки |
| `orders` | число заказов за квартал, 0–15; растёт с доходом — признаки коррелируют |
| `spend` | траты за квартал, ₽ ≈ 0,035·income + 2 550·orders + шум; `np.linalg.lstsq` на (1, income, orders) даёт w ≈ [205; 0,0347; 2 550] |

Для матрицы «клиенты × товары» (косинусная близость товаров по покупкам) берите настоящие покупки из `data/shop/shop.sqlite`: таблицы `order_items` и `orders` (52 клиента с заказами, из них 51 с оплаченными; 32 товара).

Окружение: Python 3.13.18, NumPy 2.5.3, pandas 3.0.5. Печатайте массивы предсказуемо: `np.set_printoptions(precision=3, suppress=True)`.
