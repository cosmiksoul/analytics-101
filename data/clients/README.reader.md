# Учебные клиенты

Общий набор данных темы 04 «Математика для данных» курса «Аналитика 101». 1 000 клиентов того же интернет-магазина, что в теме 03 (набор `data/shop/`). Данные учебные: их сделал `gen.py` с зерном 404.

## Файлы

| файл | что это |
|---|---|
| `clients.csv` | 1 000 строк, по строке на клиента |
| `gen.py` | Генератор: пересобирает `clients.csv` и печатает сводку |

## Столбцы

| столбец | что это |
|---|---|
| `client_id` | номер клиента, 1–1000 |
| `age` | возраст, 18–70 лет |
| `income` | доход в месяц, ₽: от 25 000 до 314 000, среднее около 79 000 |
| `orders` | число заказов за квартал, 0–15 |
| `spend` | траты за квартал, ₽ |

В данные нарочно заложено то, на чём учат страницы:

- доход в рублях в тысячи раз крупнее возраста и числа заказов — на нём видно, зачем масштабировать признаки;
- число заказов растёт с доходом, а траты — с доходом и заказами: признаки коррелируют;
- траты описывает формула 205 + 0,0347 · доход + 2 550 · заказы плюс шум. `np.linalg.lstsq` находит веса 204,6891; 0,0347; 2 549,5291.

## Как подключиться

Код страниц запускается из корня папки с материалами:

```python
import pandas as pd
df = pd.read_csv("data/clients/clients.csv")
X = df[["age", "income", "orders"]].to_numpy()   # матрица (1000, 3)
```

Чтобы пересобрать файл: `python data/clients/gen.py`. Результат совпадает с `clients.csv` побайтно.
